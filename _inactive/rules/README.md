# rules · 项目级硬规则草案（未启用）

## 分层（若启用）

| 文件 | 放什么 | 不放什么 |
|---|---|---|
| `AGENTS.md` | 通用：目标、命令、当前迁移状态、硬门禁、文件分工 | 工具特有内容 |
| `CLAUDE.md` | Claude Code 专用导入与命令，**只放工具差异** | 复制 AGENTS.md 原文 |
| `.cursor/rules/*.mdc` | Cursor 专用路径/描述触发 | 复制 AGENTS.md 原文 |

**不同规则文件对同一行为给出冲突指令时，模型可能任意选择** —— 这是硬约束，
所以通用规则只在一处定义。

## 写法要求

- **写成可观测命令，不写愿望句**
  - ❌ "代码要稳定""尽量保留功能""注意边界情况"
  - ✅ `python3 scripts/coverage_gate.py ledger/unknown.md ledger/features.md`
  - ✅ golden 变化必须产生 diff 并进入 review
- **控制篇幅**（超约 200 行会消耗更多上下文并可能降低遵守度）
- **生命周期内必须执行的约束写成 hook / CI**，不只写进规则文件
