# 03 · 像素级对齐

- 视觉：间距 / 尺寸 / 颜色 / 图标 / 圆角 / 阴影 / **动效时长与缓动曲线** / 各状态样式
- 交互：手势每个阶段、阈值与死区、让位与回弹、自动滚动、异常残留是否清理
- 数据：字段集、默认值、序列化格式与命名、编码（BOM）、迁移兼容
- 行为：**文案措辞原文**、错误提示、时序与防抖、失败/中断后的状态、退出兜底

## 纪律
- 每个功能卡的【边界】【异常】两栏不许空着
- 每完成一个模块，走一遍原版真实操作路径，逐处不一致记成新条目
- **不比对就宣称"对齐了"是不允许的**
- 不许用"这个差不多""这是体验优化以后再说"跳过任何一条
