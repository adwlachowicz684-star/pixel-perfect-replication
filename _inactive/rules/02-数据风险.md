# 02 · 数据风险

- 读不出来时**禁止**静默返回默认值：必须区分「文件不存在」与「读不出来」
- 事务原子：load 与 save 必须在同一临界区（只在写时加锁挡不住覆盖）
- 锁可重入：`with_config` 里调 `with_records` 不得自己等自己
- 异常路径放锁：用 RAII（drop 释放），不要手动 unlock
- 检测到损坏只是第一步，**拦住后续写入**才是保住现场的那道闸
- 必须留逃生口：用户删掉损坏文件后自动放行，否则程序永久锁死
