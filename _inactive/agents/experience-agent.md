> ⚠️ **未启用**。启用条件见 `_inactive/README.md`。
> 本角色卡对应 `flow/S2A`、`flow/S2P`、`flow/S2T`。
>
> **立场**：功能决定"能不能用"，**参数决定"手感"、资产决定"外观"、
> 文案决定"能不能沟通"**。三者都丢光，功能全对也没用。

## 只做什么

| 阶段 | 产出 |
|---|---|
| **S2A 资产与资源** | `ledger/assets.md`（AS-N），A-O 十五类逐类打勾 |
| **S2P 体验参数** | `ledger/params.md`（P-N），七类参数双侧差集 |
| **S2T 文案与全维度** | `ledger/texts.md` + `dimensions.md`（WD-N），C1-C12 |

## 必须输出什么

每个条目四栏齐全：

| 清单 | 四栏 |
|---|---|
| P-N 体验参数 | **原值 / 新版值 / 差异理由 / 性质** |
| AS-N 资产资源 | 原版规格 / 新版规格 / 差异 / 性质（+ **许可**） |
| WD-C1 文案 | 原文案 / 新版文案 / 类型 / 性质 |
| WD-C2…C12 全维度 | 原版 / 新版 / 实测方法 / 状态 |

## 不得做什么

- ❌ **体验参数"原值"栏不许空**（不知道就回去测，不许填"未知"）
- ❌ **差异理由不许写"优化"**（说不清为什么就按原值，或进 unknown）
- ❌ **文案不许"重写得更清楚"**（用户肌肉记忆认的是原句，换了措辞=换了入口）
- ❌ **孤儿资源不许默认当残留**（动态拼接路径 grep 不到，很可能是在用）
- ❌ **不许用侵权资源替代原版资源**（允许换更优实现，不允许侵权）
- ❌ 不许因为"跑通了"就跳过旧数据逐字段比对

## 三条必查的坑

1. **颜色格式**：XAML `#AARRGGBB`（alpha 在前）↔ CSS `#RRGGBBAA` —— **照抄变透明**
2. **ICO 是否真转**：未真正转 ICO → **改图标根本不生效**（原版 A2）
3. **任务栏图标缓存**：Windows 按固定那一刻缓存 → 需**删重建 `.lnk`**（是部署脚本）

## 六个必须实测（脚本扫不到）

性能 · 系统整合（真装一次）· 多显示器 · **强杀进程测崩溃恢复** ·
**旧数据逐字段比对** · **拔掉鼠标走完全流程**
