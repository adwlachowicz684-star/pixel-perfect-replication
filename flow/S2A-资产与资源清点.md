# S2A · 资产与资源清点

> **为什么单独立一张卡**：视觉像素藏在**资源**里，不在逻辑里。
> 功能清单上不会写图标和音效，README 也不会写——
> **不整份扫一遍，就会整类丢失。**
>
> 与 S2P 的分工：S2P 管**数值**（参数），S2A 管**素材**（文件与规格）。

---

## 一、输入

- 原版资源目录（图标 / 字体 / 图片 / 音效 / 光标 …）
- 原版代码目录（用于引用计数）
- 新版对应目录

---

## 二、动作

### 第 1 步：自动清点（双侧都跑）

```bash
python3 scripts/asset_inventory.py --src <原版资源> --code <原版代码> --out assets-old.csv --gate
python3 scripts/asset_inventory.py --src <新版资源> --code <新版代码> --out assets-new.csv --gate
python3 scripts/asset_inventory.py --src <原版资源> --code <原版代码> --out assets-old.csv --list-license
```

**脚本输出三类**：

| 输出 | 含义 | 处置 |
|---|---|---|
| 资源清单 CSV | 路径/类别/大小/hash/引用数 | 逐条落 AS-N |
| ⚠️ **孤儿资源** | 文件存在但 0 引用 | **不许默认当残留** —— 动态拼接路径 grep 不到，可能是动态加载 |
| ❌ **悬空引用** | 代码引用了但文件不存在 | **硬错误**，运行时必然取不到资源 |

### 第 2 步：按十五类逐类打勾

完整清单见 `references/资产与资源总清单.md`，A–O 十五类：

```
A 颜色  B 动效  C 阴影层次  D 图标  E 图片插画
F 字体  G 音效  H 光标      I 状态样式矩阵  J 尺寸布局
K 资源组织  L 许可合规  M 系统整合  N 本地化  O 主题皮肤
```

**挖不动时对照本表查"还有哪一类没碰过"** ——
这是穷尽挖掘在资源维度的具体抓手。

### 第 3 步：三张必查的坑表

#### 坑 1：颜色格式（WPF ↔ Web）

```
XAML:  #AARRGGBB   （alpha 在前）
CSS :  #RRGGBBAA   （alpha 在后）
```
**照抄会变成完全透明或完全不透明。** 逐个换算，不能复制粘贴。

#### 坑 2：ICO 是否真的转了

原版 A2 修复记录：**图片未真正转 ICO → 改图标根本不生效。**
清单里必须有"图标格式是否真实生效"这一栏，**不能只写"有图标"**。

#### 坑 3：系统整合资源改了不生效

- **任务栏图标**：Windows **按固定那一刻缓存**，改了不生效，需**删重建 `.lnk`**
- 托盘图标、文件关联图标、右键菜单图标同理
- 高 DPI manifest 未声明 → 高分屏模糊

**这些不是代码问题，是部署脚本的一部分。**

### 第 4 步：状态样式矩阵（I 类，最常漏的组织方式）★★

**不要按控件记样式，要按「控件 × 状态」矩阵记。**

| 状态 | 必记 |
|---|---|
| normal / hover / pressed | 基础三态 |
| **focus** | 鼠标点击后的焦点 |
| **focus-visible** ★ | **键盘焦点，与 focus 不同，常漏** |
| disabled | 颜色/透明度/光标/是否响应事件 |
| selected / active | 选中 |
| loading / error | 加载与错误态 |
| readonly | 只读（**与 disabled 不同**：可选中可复制） |

还要记**触发器优先级与顺序**（XAML ↔ CSS 完全对应）
以及**复合态**（hover + selected、disabled + selected）。

### 第 5 步：许可合规表（L 类，必填）★★

```bash
python3 scripts/asset_inventory.py --src <资源> --code <代码> --out assets.csv --list-license
```

| 资源 | 来源 | 许可 | 可否商用 | 可否嵌入 | 是否需署名 |
|---|---|---|---|---|---|
| Custom.ttf | 官网下载 | **待确认** | ? | ? | ? |
| click.wav | 素材站 | CC-BY | 是 | 是 | **需署名** |

**这是最容易忽略、代价最大的一类。** 迁移时资源常被"重新下载个差不多的"替代：
- 原资源是商业授权 → 免费替代品反而**丢失功能**（字重缺失、图标不全）
- 原资源免费但需署名 → 漏掉署名就是**违约**

## 三、用户没想到但一定会踩的几类

| 类 | 为什么没想到 | 踩了会怎样 |
|---|---|---|
| **I 状态样式矩阵** | 习惯按控件记，不按状态记 | 某个状态下长得不对，测试也测不到 |
| **focus-visible** | 用鼠标测，根本触发不到 | 键盘用户完全没法用 |
| **B 退场动画 / 中断行为** | 只关注"怎么出现" | "消失得很突兀" |
| **L 许可合规** | 不是技术问题 | 仅 `third_party` 需确认；**自有项目跳过** |
| **M 系统整合资源** | 不在代码里，在注册表/快捷方式里 | 改了不生效，还以为是代码 bug |
| **G 音效** | 桌面程序有，Web 常直接不迁 | 用户觉得"少了点什么" |
| **N RTL 布局** | 中文场景用不上 | 支持多语言后整份样式要镜像 |

## 五、门禁

- [ ] 十五类**逐类打勾**，无空类
- [ ] **无悬空引用**（`--gate` 退出码 0）
- [ ] 孤儿资源已判定（残留 vs 动态加载），**没有"默认当残留"的**
- [ ] 颜色格式换算已逐条核对（`#AARRGGBB` ↔ `#RRGGBBAA`）
- [ ] ICO 是否真实生效已验证（不是"有图标文件"就行）
- [ ] **状态样式矩阵无空格**（尤其 focus-visible）
- [ ] **许可合规表已填**，无"待确认"未跟进项
- [ ] 系统整合资源（任务栏/托盘/.lnk/高DPI）已列入部署脚本

## 六、不通过怎么办

| 情况 | 处置 |
|---|---|
| 有悬空引用 | 硬错误，必须先修；运行时必然取不到资源 |
| 孤儿资源判断不了 | **先迁着**，标注"疑似残留待确认"；**不许默认不迁** |
| 字体许可查不到 | `third_party` 时标待确认；**`self` 时直接放行**，不影响自有项目重制 |
| 某状态样式测不出来 | 用状态夹具构造（见 `S7V`），**不许留空** |
| ICO 不确定是否生效 | 实测：改图标后看系统是否真的换了（原版 A2 就是这坑） |
| 任务栏图标改了不生效 | 不是代码问题；删重建 `.lnk`，写进部署脚本 |

## 七、与 S2P 的关系

| | S2P 体验参数 | S2A 资产资源 |
|---|---|---|
| 管什么 | **数值**（tips 延迟 500ms、死区 6px） | **素材**（图标、字体、音效、色板） |
| 脚本 | `param_extract.py` | `asset_inventory.py` |
| 丢了会怎样 | 手感变了，说不出哪里 | 缺图、缺音、长得不对 |

**两者都要做** —— 一个管"节奏"，一个管"素材"。
