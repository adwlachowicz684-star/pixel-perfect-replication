# S2P · 体验参数提取

> **为什么单独一张卡**：功能决定"能不能用"，参数决定"用起来像不像"。
> 功能全对但参数全丢，用户的感受就是"说不出哪里不对"。
>
> **立场**：**可以不照搬，但必须知道搬前是什么样。**

---

## 一、输入

- 原版源码树（XAML / C# / 其它）
- 新版源码树
- （可选）能运行的原版程序 —— 用于实测源码里没有的参数

---

## 二、动作

### 第 1 步：双侧自动提取

```bash
python3 scripts/param_extract.py --src <原版src> --out work/ledger/params-old.csv
python3 scripts/param_extract.py --src <新版src> --out work/ledger/params-new.csv
```

脚本覆盖 XAML / C# / CSS / TS-TSX / Rust / JSON，输出七类参数：
**尺寸间距 / 时序 / 动画 / 阈值 / 颜色透明度 / 字体 / 层级圆角**

### 第 2 步：双侧差集（这一步才是重点）

```bash
python3 scripts/param_extract.py --compare --old params-old.csv --new params-new.csv --gate
```

| 差集 | 含义 | 处置 |
|---|---|---|
| 🔄 **疑似改名** | 值一致，命名不同 | 确认后记入别名，**不算差异** |
| ❌ **原版有、新版无** | **会丢失的体验** | 硬阻塞，必须落 P-N 卡并补 |
| ⚠️ **值不同** | 有意变更 or 漂移 | 必须判定性质 |
| ℹ️ **新版多出** | 增强项 | 记入反向清单（勿删） |

**实证**（本脚本样例工程跑出来的结果）：

```
❌ 原版有、新版无：lineheight=18 / debounce=400ms / duration=180ms
                 / interval=400ms / showdelay=500ms / 拖拽阈值=6.0
   ← 时序与阈值类几乎全丢，正是"不记录就会消失"的那批
⚠️ 值不同：fontsize 13→12；margin 8,4,8,4 → 4px 8px（⚠️ 顺序约定不同）
🔄 疑似改名：BorderThickness→borderWidth、CornerRadius→borderRadius
```

### 第 3 步：脚本扫不到的手工补

```bash
# 静态资源引用（值在别处定义，脚本取不到）
re.findall(r'x:Key="(\w+)"', t)      # 顺着资源键找真实定义

# 关键词全库扫
grep -rn "Interval\|Duration\|Delay\|debounce\|防抖\|延迟\|轮询" --include=*.cs .
grep -rn "Threshold\|DeadZone\|死区\|阈值\|epsilon" --include=*.cs .
grep -rn "transition\|animation\|cubic-bezier" --include=*.css .
```

**顺资源键找真实定义很重要** —— 那往往是一整个主题的参数集。

### 第 4 步：运行原版实测（源码里根本没有的）

| 参数 | 怎么测 |
|---|---|
| tips 实际弹出延迟 | 录屏数帧 / 打点计时 |
| 动画真实时长 | 录屏按帧数 × 帧率 |
| 滚动条宽、系统字体度量 | 原版运行实测 + 截图量像素 |
| 默认控件尺寸（未显式设 Width 的） | 截图量像素 |
| 双击 / 长按判定 | 手动试 + 计时 |

证据等级标 **`runtime-measured`**，写进证据卡并附**测量方法**。

### 第 5 步：每个参数落一张 P-N 卡

四栏必须全填：**原值 / 新版值 / 差异理由 / 性质**

| 性质 | 含义 | 处置 |
|---|---|---|
| **等比迁移** | px→px 语义不变（圆角 4→4） | 照搬 |
| **需缩放** | 受 DPI / 字体度量 / DPR 影响 | 换算后**记下公式** |
| **平台惯例** | Windows 惯例 ≠ Web 惯例 | 记录差异，按新平台定 |
| **技术权宜** | 当年受技术限制 | ⭐ 换更好方案 |
| **有意变更** | 明确要改 | 登记 + golden 标 `intentional-change` |

**"差异理由"栏不许空** —— 空着等于说不清为什么变，三个月后没人敢动。

## 三、三个实证陷阱（脚本已处理，手工挖时注意）

| 陷阱 | 后果 |
|---|---|
| `\bThreshold\b` 抓不到 `dragThreshold` | 驼峰命名的参数**全漏** |
| `FontSize` 与 `fontSize` 当两个参数 | 差集全是噪音，真差异看不见 |
| `TimeSpan.FromMilliseconds(180)` 被当秒 | **180 变 180000ms** |
| `Margin="8,4,8,4"` 被逗号截断 | 四元组只拿到 `8` |

**⚠️ 脚本处理不了、必须人看的一条**：
**XAML 是「左,上,右,下」，CSS 是「上 右 下 左」。**
脚本会提示"数值集合相同但顺序不同"，但**别直接抄**。

## 四、常见遗漏自检（逐项打勾）

- [ ] tips / tooltip 的 **ShowDelay / HideDelay / 自动关闭时长**
- [ ] 各类**防抖与节流**（输入、滚动、连锁发送）
- [ ] **拖拽死区**与落点容差
- [ ] **自动滚动**触发边界与速度
- [ ] 双击 / 长按 / 三击的**时间阈值**
- [ ] 轮询间隔、超时、重试次数与退避
- [ ] 动画时长**与缓动曲线**（不只是时长）
- [ ] 未显式设置的**系统默认值**（需实测）
- [ ] 禁用态 / hover 态 / 按下态的**具体数值**
- [ ] 快捷键的**连按判定窗口**

| `ledger/params.md` | 体验参数清单（P-N，编号固定） |

## 六、门禁

- [ ] 双侧提取都跑过
- [ ] 差集四类都已处置（改名已确认、缺失已补或已登记、值不同已判性质、多出已进勿删）
- [ ] **无"原版有新版无"未处置项**（`--gate` 退出码 0）
- [ ] 每个 P-N 卡四栏齐全，**差异理由不为空**
- [ ] 需实测的参数已标 `runtime-measured` 并附测量方法

## 七、不通过怎么办

| 情况 | 处置 |
|---|---|
| 新版根本没有某参数 | 落 P-N 卡标"缺失" → 这是功能缺口，**必须补**（时序类尤其） |
| 值不同但说不清为什么 | **不许填"优化"** —— 查不出理由就按原值，或进 unknown |
| 参数受 DPI 影响不知怎么换算 | 标"需缩放" + 写清换算公式；算不出就进 unknown |
| 怀疑是改名 | 脚本已提示"疑似改名"；确认后记入别名，**不算差异** |
| 系统默认值测不出来 | 标 `runtime-measured` 失败 + 进 unknown，**不许猜** |
