# S2T · 文案与全维度

> **为什么单独立一张卡**：
> - 参数（S2P）管**数值**，资产（S2A）管**素材**
> - 本篇管**剩下所有用户能感知的东西**：文案、状态边界、可访问性、性能、
>   系统整合、输入设备、状态持久化、升级迁移、安全、国际化、时间时区
>
> **共同特征**：功能清单上不会写，README 也不会写，
> 丢了之后用户说"感觉变了但说不出哪里变了"。

---

## 一、输入

- 原版源码树（含 XAML / C# / 资源文件）
- 新版源码树
- 原版可运行程序（用于实测性能、系统整合、多显示器等）

---

## 二、动作

### 第 1 步：文案自动提取与差集（C1）★

```bash
python3 scripts/text_extract.py --src <原版> --out texts-old.csv
python3 scripts/text_extract.py --src <新版> --out texts-new.csv
python3 scripts/text_extract.py --compare --old texts-old.csv --new texts-new.csv --gate
```

**三类输出**：

| 输出 | 含义 | 处置 |
|---|---|---|
| 🔄 **疑似改写** | 措辞变了（相似度 ≥50%） | **最容易丢体验的一类**，要么补回要么登记有意变更 |
| ❌ **原版有新版无** | 丢失的文案 | 硬阻塞：补回或登记 |
| ℹ️ **新版多出** | 增强 | 记入反向清单 |

**实证**（样例工程）：

```
🔄 疑似改写：「保存成功」→「操作成功」，「确定」→「确认」
❌ 丢失：保存当前设置 / 名称不合法，请重新输入 / 文件被占用，无法写入
        / 没有找到匹配的项目 / 配置加载失败
```

**⚠️ 迁移时最常见的错误**：不看原文案，直接"重写得更清楚"。
**用户的肌肉记忆认的是原句**——换了措辞等于换了入口。

**脚本用序列相似度而非字符集合**：短中文串里同义词替换（确定→确认）
字符几乎不重叠，集合法只有 0.33 会漏掉。

### 第 3 步：必须实测的（脚本扫不到）

| 维度 | 怎么测 |
|---|---|
| **C4 性能** | 冷启动计时、10000 项列表滚动、长操作能否取消 |
| **C5 系统整合** | 实际安装一次：文件关联、右键菜单、托盘、开机自启、卸载残留 |
| **C6 多显示器** | 两台不同 DPI 显示器间拖窗口 |
| **C7 崩溃恢复** | **强杀进程**后重启，看未保存内容能否找回 |
| **C8 数据迁移** | 用旧版本真实数据升级，逐字段比对有没有静默丢弃 |
| **C3 可访问性** | **拔掉鼠标**走完全流程；Tab 看会不会跑出模态 |

### 第 4 步：三个"多半没想到但一定会踩"

| 维度 | 踩了会怎样 |
|---|---|
| **C2-3 防闪烁延迟** | 请求 <200ms 时不显示 loading，否则**一直闪** |
| **C2-5 部分失败** | 批量 10 个成功 8 个，界面不知道怎么显示 |
| **C3-3 焦点陷阱** | 模态里 Tab 跑到背后的界面（用鼠标测不出来） |
| **C7-7 崩溃恢复** | 正常退出测不出；崩溃丢内容是最痛的体验 |
| **C8-2 字段静默丢弃** | 数据**永久丢失**且无提示（实证 `clusters` 字段） |
| **C6-6 多显示器** | 单屏开发，不同 DPI 下拖窗口 → 模糊或错位 |

## 四、门禁

- [ ] 文案双侧差集已跑，**无未处置的丢失文案**（`--gate` 退出码 0）
- [ ] **疑似改写项已逐条判定**（补回原文案 or 登记为有意变更）
- [ ] C1–C12 **逐类打勾**，无空类
- [ ] 六个"必须实测"项已实测（性能/系统整合/多显示器/崩溃恢复/数据迁移/无鼠标）
- [ ] **C8 数据迁移逐字段比对过**，无静默丢弃
- [ ] C3 可访问性：拔鼠标走完流程、模态无焦点陷阱

## 五、不通过怎么办

| 情况 | 处置 |
|---|---|
| 丢失了错误提示文案 | **视同功能缺口** —— 用户遇到了但不知道发生了什么 |
| 文案被"重写得更清楚" | 要么补回原文，要么登记有意变更，**不许默认保留新版措辞** |
| 崩溃恢复测不出来 | 如实记 unknown + 说明受限；**不许包装成"已支持"** |
| 旧数据字段疑似丢弃 | **最高优先级**：数据永久丢失，必须逐字段比对 |
| 多显示器环境不具备 | 标记受限；但**高 DPI 缩放必须测**（单屏也能测） |
| 术语不统一 | 建术语表统一，不是"顺手改一个" |

## 六、与 S2P / S2A 的关系

| | S2P 体验参数 | S2A 资产资源 | S2T 文案与全维度 |
|---|---|---|---|
| 管什么 | **数值**（节奏） | **素材**（外观） | **沟通与能不能用** |
| 脚本 | `param_extract.py` | `asset_inventory.py` | `text_extract.py` |
| 丢了会怎样 | 手感变了 | 缺图缺音 | 用户看不懂、数据丢失、部分人不能用 |

**三张卡都要走完** —— 只做功能是"能用"，三张都做完才是"像原来那个"。
