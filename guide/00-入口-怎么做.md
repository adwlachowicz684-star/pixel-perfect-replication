# guide/ —— 只写「怎么做」

> **本目录只回答一个问题：复刻这件事，具体怎么做。**
> 所有"不能怎么做 / 不许 / 禁止 / 审核边界"都在 `../audit/`，**不在这里**。
> 这样分工是为了让执行时不被禁令打断，审核时不被流程稀释。

| 文件 | 回答什么 |
|---|---|
| `01-七阶段流程.md` | **先从哪一步开始，再到哪一步** |
| `02-怎么取证.md` | 原版表现**怎么测出来**，测什么、用什么测 |
| `03-怎么记录.md` | 测出来的东西**记成什么样**，记到哪 |
| `04-怎么判定与偏离.md` | 每条性质**怎么定**，想改的话**怎么改才算有意识地改** |
| `05-怎么验收.md` | 做完之后**怎么证明做完了** |
| `06-游戏引擎场景怎么做.md` | 跨引擎搬迁 / 重制 / 二次创作时**多做的几步** |

## 使用顺序

```
01（流程定位）→ 02（取证）→ 03（记录）→ 04（判定）
    → 实现 → 05（验收）
                 ↑
          中途随时回 02 补测
```

**游戏项目**：在 `03` 之后插 `06`，再回到 `04`。

## 一句话记住这套流程

> **先像素级记录原版表现，再有意识地偏离。**
>
> 前半句在 `02` `03`，后半句在 `04`。**顺序不能倒** ——
> 没记录过的东西，没有资格谈"偏离"。
