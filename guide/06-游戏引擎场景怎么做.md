## 一、多做的第一件事：坐标系

> 🔴 **错了会弥漫到全项目，所以放在最前面。**

| 项 | Unreal | Unity / Godot |
|---|---|---|
| 单位 | **厘米** | 米（**速度重力直接搬差 100 倍**） |
| 前向 | +X | Godot 是 **-Z**（模型/相机/AI 朝向全反） |
| 手性 | 左手 | 右手（**叉积与 winding order 翻转**） |

**法线贴图绿通道**：OpenGL(+Y) vs DirectX(-Y) —— 反了光照全错。

## 二、四分类在游戏里的具体边界

| 分类 | 游戏中的例子 |
|---|---|
| `must-match` | 手感、数值、碰撞、时序、关卡布局、输入响应、判定盒、RNG 序列 |
| `may-evolve` | 画质、光照、特效、模型精度、UI |
| `should-reinvent` | Nanite / Lumen / GI |
| `explicit-new` | 新关卡、新角色、新机制 |

## 三、🔑 必须逐项记录的"极细"清单（历史踩坑精选）

**坐标与物理**
- 固定时间步必须与引擎一致（否则跳跃高度、摩擦、阻尼全变）
- 概念同名 ≠ 语义相同：Prefab / Blueprint / PackedScene 嵌套与变体机制完全不同

**手感**
- 顿帧关键是"**冻结谁**"，不是冻结多久
- 判定盒是**每帧多重集合**，不是三个矩形
- coyote time 是**有限窗口**，要同时记 tick 数与毫秒
- 可变跳跃三类语义不能统称 variable jump
- 微停顿 1–3 帧要逐项记录，帧生成帧**必须标 interpolated**

**输入**
- 手柄**至少三个独立死区**（摇杆径向/轴向 · 扳机阈值 · 外圈加速）
- 鼠标先确认走原始输入还是系统指针
- 键盘**禁止把 `KeyW` 写死成扫描码**（AZERTY/QWERTZ/Dvorak 会改肌肉记忆）

**时间与随机**
- 四种暂停失真分别记录，不合并
- `scale = 0.5` 与 `scale *= 0.5` **不是同义**
- 算法名要记全：字长、参数、初始化、索引位置、进位、输出变换
- **RNG 固化时机**比"是否固化"更隐蔽

**破坏与连锁**
- 破坏粒度不是视觉档位，是**玩法结果的函数**
- 承重是**显式连接图属性**
- 碎块消失是**四个独立计时器**
- 元素传播**更新顺序决定确定性**

**绳索**
- 换求解器后"**同一参数是伪命题**"
- 孤岛内**迭代次数取最大值**，改一个会影响其他物体

**存档与痕迹**
- 未知存档字段**不得丢弃**
- 迁移要支持 v1→v2、v2→v3、**以及 v1→v3**
- 人格化痕迹五类：机械 / 语义 / 平台专属 / 表达性资产 / **元历史**

**叙事**
- 过场是**控制权矩阵**（八态 × 每帧九个所有者字段）
- "不可跳过"**必须被证明**

**载体与权利（第三十九轮）**
- 触控是**连续触点拓扑**：按 `pointerId` 管生命周期；滑动/长按/点击**在同一状态机竞争**
- 虚拟摇杆死区与漂移、陀螺仪校准、掌机休眠恢复
- **官方编辑器去留是产品决策**；热重载只覆盖可丢弃/可重放/可重声明层
- **保底计数必须原子写入服务端**，不能只在客户端 `PlayerPrefs`
- 数据布局记 AoS/SoA/**AoSoA** · 对齐 · 热冷分离 · 64B 缓存行
- **SIMD 保留标量黄金路径**，结果与参考一致才启用

**意义层（第四十轮）——「玩家读出什么」**
- 🔑 **事实态 + 表达态 + 可辨态**：只有盲测能证明复刻有效
- 脚步是「可见材质→命中材质→声音映射→玩家识别」四段链条
- **「楼上还是楼下」必须独立字段**（不是 HRTF 附属品）
- 成长记**五通道**与 `delta_direction`（含 inversion）；**沉默事实不许补成"更爽"**
- 聚焦生命周期 19 事件逐项录（🔴 **"恢复后正常"不算**）
- 跨通道节拍偏移用 `beat_clock` 单一时间轴
- **刻意坏味清单**：任何修复都须有偏离许可

**认知与耐力（第四十一轮）——「意义装进记忆、肌肉与信任了吗」**
- 🔑 **心智地图 ≠ NavMesh**："AI 能过去" ≠ "玩家知道能过去"；要同时做视觉回归 + 认知回归
- **迷路三分类**：探索性（设计资产）/ 可读性（缺陷）/ 拓扑性（缺陷）
- **决策承诺语义**：后果四级、不可逆五轴、🔑 **原版故意隐瞒是 must-match**
- 🔑 **仪式感**：1.2 秒关门声缩到 0.4 秒，玩家不再感到选择落地
- 🔴 **SL 可行性实测**，不得因云同步意外消除
- **长时间漂移五阶段**（0–15/15–30/30–60/60–120/120–180+）
- 🔴 **操作自动化是精通也是故障源**（肌肉记忆被打破）
- 🔑 **成功包络非平均成功率**；**责任归因六方**，client view 与 server truth 分轨

**推断层（第四十二轮）——「玩家据此以为会发生什么」**
- 🔑 **常识违反若可重复，就不是瑕疵，而是资产**（火烧不燃木桶、水下点火、纸挡箭）
- 🔴 `Wood_Barrel_01` 不可燃但 `Wood_Crate` 可燃——**资源名不能代替运行时测试**
- 🔑 **OOB 是原版地图的一部分**，不是物理 bug；边界厚度**测距离非布尔**
- 🔑 **通道权威性按状态机**给，不按固定权重；四级治理不得越级
- 🔴 **动画明显命中但判定未中＝游戏撒谎**
- 🔑 **复现随机接口，不是只复现分布**；`designed_illusion` 必须明确
- 🔑 **可解释性四级**（含 counterfactual）；**设备老化与校准**进 `device_profile`

**关系状态（第四十三轮）——「系统之间的时间接缝」**
- 🔑 **玩家关闭游戏后，原版如何记住自己正准备做什么？** 关键不是"玩了多久"，而是**最后 120 秒**发生了什么
- 🔑 **用布尔 `seen` 会误判"此后都可跳过"** —— 要四层计数 × 语境标签
- 🔑 **跳过是控制权迁移，不是删内容**：必须应用跳过后的目标状态
- 🔑 **幽灵六级**：门后没有模型 ≠ 没有承诺（可能有声音/风/光照/碰撞）
- 🔑 **第一次三层**：一次性事实 / 叙事标记 / **不可再生情绪**；重制不得剧透
- 🔑 **回归玩家第一分钟不是新手教学，而是"游戏还认不认得我"**
- 🔑 笨拙不是残障；**共谋不揭穿**（假选择 / QTE / 假开放保持）

**身份与时序（第四十四轮）**
- 🔑 **名称只是标签，身份才是契约** —— 同名剑在背包第 1 格和第 5 格不等价
- 🔴 **把背包压缩为「按定义去重＋数量」，就消灭了玩家记得的每一把剑**
- 🔑 **整理背包本身也可能改变结果**（`observed_slot_history` 不是 `instance_id`）
- 🔑 **键位重映射只解决「E 还是 F」，不解决「提前 4 帧按下是否还有效」**
- 🔑 **无效输入的副作用**才是 must-match，不是"命令是否成功"
- 🔑 **社区组合技是一等资产** —— 分模块测试会天然漏掉系统接缝
- 🔑 **惯例层与原版层并存**：反惯例不是落后，是身份
- 🔑 **错过的稀缺性本身就是内容**；**输得好看**是连续情绪曲线

**社会层与版本地层（第四十五轮）——四条外部依赖链**
- 🔑 **老玩家教的是旧版本** —— 知识声明三层：事实观察 / 解释断言 / 证据链
- 🔑 **假可玩性**：界面先承诺、系统再拒绝；教程临时能力会让玩家错误学习交互语法
- 🔑 **玩家第二职业**（矿工 · 速通者 · Modder）依赖原版的**可观测裂缝**
- 🔑 **版本地层是 DAG 不是时间轴**：标题相同 ≠ 构件相同
- 🔴 **地区版不能预设"只有文本不同"，也不得写"日版总是更难"**
- 🔑 **真正的仪式支持是「允许慢」，不是「强迫慢」**
- 🔑 **原版没有成就 ≠ 玩家不苦行**；辅助模式会改变苦行资格与身份

**外围层与身体接口（第四十六轮）**
- 🔑 **原版"游戏"不止于进程内画面** —— 启动器 · 覆盖层 · 平台账号 · 校准 · 失败恢复
- 🔑 **外围十三类按状态机取证**，🔴 **不能从 UI 截图倒推内部契约**
- 🔑 **GOG：客户端可缺是硬要求**（Init 失败只禁用成就/排行榜/统计/多人）
- 🔑 **玩家自救是第二控制流**：消除痛苦 ≠ 错误，删掉玩家共同语言才是偏离
- 🔑 **物理外设是身体动作的语义映射**：饱和区 · 扭矩曲线 · 断电残留扭矩 · 离屏装填
- 🔑 **游玩环境考古**：客厅 ≠ 书房；WCAG 只作测量尺度
- 🔑 **通关后的世界是叙事状态机**；**照片模式不是"可移除的截图键"**

**生活层与文化层（第四十七轮）**
- 🔑 **"打完这个 BOSS 就睡"** —— BOSS 战同时改变时间预期 · 重试成本 · 存档边界 · 退出节点
- 🔑 **暂停的可用性取决于系统能否冻结**，不是按钮是否存在
- 🔑 **玩家容忍不可预测，却不容忍结果无法归因**；黑箱更公平是错误推论
- 🔑 **文化是数值 · 颜色 · 手势 · 时间 · 姓名的语义层**；源语言默认无文化是常见盲点
- 🔑 **排序稳定性是首要 must-match**：不能用稳定排序悄然取代原版未定义顺序
- 🔑 **Mod 加载顺序决定功能**；**命名长度是截断契约不是字符串上限**
- 🔑 **删除权不是删号**；**第三空间不是低效率空间**

**元协议层（第四十八轮）**
- 🔑 **对象不是菜单里有没有功能，而是玩家如何借系统理解世界、表达意图并承担后果**
- 🔑 **统一 ping 会抹平位置信号 · 身份表演 · 持久涂鸦的差异**
- 🔑 **"能不能反悔"只决定后果多严重，"行动前知道什么"才决定选择属于谁**
- 🔑 **行为记忆是带证据和期限的缓存**；被监视感来自无法关闭的影响
- 🔑 **外部工具是接口生态不是作弊**；`damage` 可能指六种不同伤害
- 🔑 **稀有度是通道同步的承诺**；屏蔽声音后能否识别层级是公平问题
- 🔑 **认知地图不是地图几何**；🔴 **沉默是规则不是空缺**

**变体与载体层（第四十九轮）**
- 🔑 **Demo 不是正式版的截短**——七态状态机，勋章可继承但奖杯不可（两条规则）
- 🔑 **存档继承是带一次性决策和不可逆分支的协议**；不得悄悄增加恢复安全网
- 🔑 **Attract Mode 假操作是刻意编排**；不能只截一张标题画面
- 🔑 **秘籍是发布内容不是调试残留**；五层输入窗口含 IME 与控制器布局
- 🔑 **旁观者是无输入权限的第二名玩家**；`(on radio)` 收音状态标注
- 🔑 **纸质地图与数字小地图是两套认知工具**；数字替身不得覆盖原版实体浏览物
- 🔑 **错误画面可能是可互动迷你关卡**；🔴 **单槽强制自动保存破坏叙事仪式**

**边缘状态层（第五十轮 · 三张状态图）**
- 🔑 **试玩机不是零售版换皮**——关电重开/程序异常/观看者离开都回到 Attract 而非上次进度
- 🔑 **倒计时是逐渐加压的中断流程**；给出宽限—等待输入—超时清场，不是立刻黑屏
- 🔑 **失败屏是完整表现资产**；🔴 **不得悄悄"修掉"以可见异常著称的版本表面**
- 🔑 **CD-KEY 是字符消歧问题**（0/O · 1/I · B/8 · G/6）；不得擅自加校验或自动纠错
- 🔑 **Credits 是版本化证据链**；排序按原版事实，🔴 **删除原作者是署名缺陷**
- 🔑 **支持者拼写不能简单改正**；为版式整齐删除众筹名单是"善意的破坏"
- 🔑 **证据态四态**（verified/secondhand/unverified/not_present）不得留空

**证据补洞与四路验收接入（第五十一轮）**
- 🔑 **街机 Attract 不是跨厂商统一定时器**——最小单位是五元组，🔴 **不能把一台机柜的 N 秒推广为行业默认值**
- 🔑 **拿不到证据就写"证据不足"**，转入实测计划；秒数与证据态不符即硬拦截
- 🔑 **Credits 是带证据链的 diff**，不是文本 dump；🔴 **删除原团队不是"品牌更新"**
- 🔑 **CD-KEY 是字符消歧问题**；原版不区分不得加校验，原版区分不得自动纠错
- 🔑 **统一时钟比统一像素阈值更重要**；构建矩阵要展开为 engine×platform×renderer×build_id
- 🔑 **整屏 diff 用于状态边界，逐帧 diff 用于循环内容**；🔴 **基线不可知只产出 observed_durations.json**
- 🔑 **物理表面以可复核尺度为 must-match**；🔴 **缺产物哈希即无法重放**

**执行层修复（第五十二轮 · 不开新主题）**
- 🔑 **"缺失 N"不是能力缺口**——先按 `kind` 拆开：`cli`(171) / `lib`(12) 才可运行，`doc`/`sdk`/`reference`(159) 本来就不能 `which`
- 🔴 **多轮追加登记必须去重**——否则会产生重名，更会产生**重复 key（YAML 后写覆盖先写，静默丢数据）**
- 🔑 **空工作区不得被读成"全绿"**——现在会显式打印"通过 0 / 共 120"并警告
- 🔑 **通过只表示"这张表填得自洽"，不表示原版行为已被取证**

**四路验收端到端（第五十三轮）**
- 🔑 `edge_pipeline.py --self-test` **真的能跑通**：fixture → capture → join → durations → report → verify
- 🔑 **缺工具的路记为 `tool_missing`/`degraded`，不计入通过**——audio 无 `fpcalc` 时输出 `numpy_fft_fallback` 并标注 `backend`
- 🔑 **`T_min/T_max` 留 null，只产出 `observed_durations.json`**——基线不可知不伪造 PASS
- 🔴 **自测通过 ≠ 原版行为已取证**——真值是我们自己造的

**SPDX 3.0 Build 接入（第五十四轮 · 先核验再落地）**
- 🔑 落地前先核一手规范，**推翻三处**：18→19 字段（必填仅 3）· `buildId` 只是 locally unique · 时间戳可省略且省略才利于可复现
- 🔑 **`buildId` 不得当全局主键**——须自加 `externalIdentifier` 全局层
- 🔑 **默认不写 `buildStartTime/EndTime`**——SPDX 官方明说省略才利于可复现
- 🔴 **Build profile 要求 3 条强制关系**（hasInput/hasOutput/invokedBy，scope=build）
- 🔑 **`buildType` 只是 hint，不能当权威真相**

**真实捕获导入（第五十五轮 · 自测 ≠ 取证）**
- 🔑 `--import` 接真实素材；🔴 **无真值时 `--verify` 被拒绝（退出码 1）**
- 🔑 **合成自测与真实取证是两条路径**——不得互相冒充
- 🔑 必须先 `ffprobe` 探测 fps/时长/音轨，**不得猜**
- 🔑 管道已通，**等待真实素材**；观测段只是观测，不是验证结论

**门禁混沌测试（第五十六轮 · 门禁数量 → 拦截率）**
- 🔑 **第一次真的去改坏台账**：101 个台账型门禁逐个 `--init` → 填违例 → 看是否阻断
- 🔑 实测 **拦截 89/101 ≈ 88%**——**门禁数量被替换成拦截率**
- 🔴 **空台账不得静默通过**（0 条 ≠ 无阻断项）
- 🔴 **枚举字段须白名单校验**——黑名单式拦不住"填错的值"
- ⚠️ 毒化只覆盖 11 类关键词，**未覆盖字段的有效性仍未知**

**毒化覆盖率（第五十七轮 · 拦截率 → 覆盖率 × 拦截率）**
- 🔑 `--coverage` 实测：**705 字段 · 616 可断言 · 覆盖率 87.4%**
- 🔴 剩余 **89 个不可断言字段**在任何毒化策略下都无法自动验证——**只能靠人工**
- 🔴 **一个假设被实测证伪**：配对字段并非主要盲区（79/80 相同毒化即被拦）
- 🔑 **两种毒化策略结果完全一致（87/101）**→ 问题在校验逻辑，不在测试方法

**语义毒化（第五十八轮 · 字段合法 ≠ 行自洽）**
- 🔑 `--strategy semantic`：用**合法值**制造**内部矛盾**（legacy=100/new=200/match=exact）
- 🔴 **白名单校验拦得住"填错的值"，拦不住"每个字段都对、整行在说谎"**
- 🔴 毒化代码须抽查真实产物——曾被 TODO 覆盖逻辑**静默失效**
- 🔴 **9 个盲区在三种完全不同的毒化下都不动**——人工必须自己看

**A 类盲区归零（第五十九轮）**
- ✅ **A 类 9 → 0**，`--self-test` 退出码 **0**（此前为 1）
- 🔴 **修的过程推翻了上一轮一半结论**：1 个脚本的 check **根本没被执行到**（`--gate` 是子命令）
- 🔑 **三种毒化结果一致，只证明"现象可靠"，不证明"原因正确"——要找原因必须读代码**
- ⚠️ 97/101 中仍有 1 项（`credits_diff`）是"接口不匹配"——**不是通过，是没测**

**门禁自身可信度（第六十轮）**
- 🔑 汇总现在同时报 **混沌拦截率** 与 **字段覆盖率**——**门禁数量会被误读为能力**
- 🔑 98/98 的分母是"能参与统计的 98 项"，**不是 101**（3 项仍 skip）
- 🔴 非 `--check` 脚本须登记 `INTERFACE_ADAPTERS`，不能留作"没测"
- ⚠️ 8 个脚本 `ENUMS` 是**推断值**，不是原版证据——若某枚举本身是 must-match 则必须取证

**未参与统计项须有明确身份（第六十一轮）**
- 🔑 `not_a_ledger`（`--init` 不是生成 CSV）· `needs_external_input`（依赖 ffmpeg 抽帧）
- 🔴 **"缺数据"不得输出成"在容差内/通过"**——与【空表即通过】同源
- 🔴 **白名单与一致性校验也会误杀**：没有 evidence 列就不做证据断言
- ⚠️ `motion_check` 的 compare 门禁**至今没被真正毒化测试过**

**门禁混沌测试（第六十二轮）**
- 🔑 拦截率 **101/101**，skip 归零（`typed` / `semantic` 两种策略一致）
- 🔑 **基线必须 rc=0**——否则"毒化后 rc≠0"没有信息量（测了个寂寞）
- 🔑 值毒化无效时改用**结构毒化（删键）**
- ⚠️ **拦截率是门禁健康度，不是复刻完成度**——合成输入只证明门禁响应内容

**读拦截率时必须同时看强证据率（第六十三轮）**
- 🔑 同样是 101/101：空台账基线**强证据仅 4**，填合法值后**强证据 89**
- 🔑 强证据 = 基线 rc=0 且毒化后 rc≠0（门禁**确实对内容敏感**）
- ⚠️ 弱证据 = 基线本来就拦 → 只证明"它会拦"，**可能测了个寂寞**
- 🔑 提升路径：`--baseline valid` → 读脚本自身 `ENUMS` → 逐脚本 `FIXTURE_OVERRIDES`

**目录完备型门禁（第六十四轮）**
- 🔑 fault_matrix / install_contract / feature_matrix 的**基线必然不干净**
- 🔑 因为「没记全」正是它们要拦的东西 → **强证据率上限不是 101 而是 98**
- 🔴 不要为它们凑一个"干净基线"——那等于先伪造完整记录再自证
- 🔑 改用 `--completeness`：**补齐一项 → 缺失计数应降一项**（已实测两个均单调）
- 🔑 台账有 **CSV / Markdown / YAML** 三种 —— 毒化必须按 `_sniff()` 结果分派
- 🔴 两个嗅探器（`_sniff` / `_is_md_table`）**结论必须一致**，否则 md 会被当 CSV 写回

> 📌 完整清单见 `references/游戏引擎复刻.md`（64 轮）。
> 📌 **不能怎么做的对应条目**见 `../audit/01-禁令总表.md` D / E / M 域。

## 四、游戏场景的验收增量

## 五、一句话

> **先像素级记录原引擎表现，再有意识地偏离。**

> 固化时机、待机相位**这类"没人写在设计文档里"的东西。
