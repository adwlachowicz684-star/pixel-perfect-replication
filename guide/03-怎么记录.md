# 怎么记录：测出来的东西记成什么样

## 一、台账是唯一真相源

所有发现都进台账（`assets/清单模板.md`），**不在聊天记录、不在脑子里**。

最小字段：

| 字段 | 内容 |
|---|---|
| `id` | 稳定编号，**不重排** |
| `name` | 功能/细节名 |
| `domain` | 所属域 |
| **`legacy_value`** | **原版值**（必填，不许空） |
| `new_value` | 新栈值 |
| **`class`** | `must-match` / `may-evolve` / `should-reinvent` / `explicit-new` |
| **`evidence`** | 证据等级 1–8 |
| `tolerance` | 允许偏差 |
| `owner` / `due` | 偏离的负责人与复审日 |

## 二、🔑 记录的颗粒度：记"参数"，不记"功能名"

| ❌ 记成这样 | ✅ 记成这样 |
|---|---|
| "有钓鱼系统" | 咬钩延迟区间、拉力曲线、卷线速度、断线阈值、挣扎节拍 |
| "中毒变绿" | **用了哪个通道**（步态/呼吸/屏边/LUT/FOV/震动/脚步/音色）+ 叠加矩阵 |
| "冷却 10 秒" | **冷却起点八候选之一**（按下/生效/动画结束/结算…） |
| "有阴影" | `shadow_authority` 五档之一 + 低配档能砍什么 |
| "随机掉落" | RNG 算法 + 字长 + 初始化 + 调用顺序 + 固化时机 |

## 三、四类"相同"要分开记

| 类 | 场景 | 判定 |
|---|---|---|
| **字节相同** | 文件 | 二进制 diff |
| **语义相同** | 契约/数据 | 解析后比较 |
| **展示相同** | UI | 渲染后比较 |
| **感知相同** | 手感/体验 | **只有这个要人测** |

> 数字即使非金融值，也**不能因"值相等"就删掉格式信息**（要记 `float_format`）。

## 四、unknown 怎么记

`unknown` 是**合法状态**，但必须：

- 写明**为什么不知道**（缺样本 / 不可复现 / 待讨论）
- 写明**谁去补、什么时候补**
- **不许留空，不许写"大概""差不多"**

## 五、偏离怎么记

每处偏离除分类外还要有：

1. **偏离了什么**（原版值 → 新值）
2. **为什么**
3. **谁批的**
4. **什么时候复审**
5. **影响哪些既有玩法 / 社区习惯**

> 缺第 3、4 项的偏离，门禁会判"未处置"并阻断。
