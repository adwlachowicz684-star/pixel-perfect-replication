# 安全信任、离线环境与无障碍深度（第十一轮）

> **本轮新增不应继续停留在静态检查器层，而应补成五条可复现的证据链**：
> 更新信任链 · 签名生命周期 · WebView/IPC 特权边界 · **真实辅助技术输出** ·
> 离线故障与系统资源行为。

## 一、A 类：安全与信任边界（**完全空白**）

```bash
python3 scripts/security_trust.py --signing    # 🔴 时间戳不是"签一次管永久"
python3 scripts/security_trust.py --update     # TUF 威胁模型
python3 scripts/security_trust.py --webview    # 按攻击路径反推
python3 scripts/security_trust.py --secrets    # 凭据：默认答案是否定
python3 scripts/security_trust.py --sandbox    # 每个 capability 要有拒绝路径
python3 scripts/security_trust.py --check ledger/security_gates.csv --gate
```

**六份文件**：`signing` · `update-trust` · `webview-acl` · `ipc-contract` ·
`secret-store` · `sandbox`
每个都同时记：原版行为 · 目标最小能力 · **负向测试** · 失败状态 · 证据制品 · 回滚条件

> 🔑 **已有依赖扫描（cargo-deny/Grype/ScanCode/REUSE）回答不了
> "谁能在哪一步替换可执行体"。**

### 1.1 🔴 时间戳不是"签一次管永久"

| 情况 | 结果 |
|---|---|
| 普通时间戳 | ✅ 锚定到签名时刻，证书过期后**仍可能验证** |
| **Lifetime Signing OID** | 🔴 **即使有时间戳，过期也失败**（或验证方设 `WTD_LIFETIME_SIGNING_FLAG`） |
| 时间戳证书不受信任 | 🔴 失败 |
| 证书吊销 | 🔴 失败 |

四个必答字段：`timestamp_authority` · `timestamp_protocol`（**RFC 3161 + SHA-256**）·
`revocation_policy` · `long_term_verification_artifacts`

**五种必测状态**（**不能只检查 `ValidSignature`**）：
CA 已吊销但签名当时有效 · 根轮转 · TSA 不可达 · 证书过期 · **Lifetime Signing**

⚠️ 不能用"Sigstore 已存在"替代原生安装器签名：Windows 要 Authenticode、
macOS 要 notary/stapler + Gatekeeper、Linux 要有包格式 digest/GPG/sigstore 选择矩阵。

### 1.2 更新信任：TUF 是协议参照，不是生产依赖

`theupdateframework/tuf`（MIT/Apache-2.0，CNCF 托管）—— 价值是强制写出
root/targets/snapshot/timestamp 四角色、**阈值签名、密钥轮转、consistent snapshot、
hash 与长度校验、回滚与冻结保护**。

> ⚠️ **参考实现不是稳定 API，不应成为生产依赖。**
> 真正可落地的是把 TUF **威胁模型**转成 `update-scenarios/` 目录。

`update-trust.md` 必答：从哪里取 index · 是否校验目标**长度** ·
何时拒绝**旧 snapshot** · 离线缓存保留多久 · **rollback 版本上限** · **root 轮换演练**

**cosign 与 TUF 职责必须分开** —— cosign 给制品与证据链签名（keyless、Fulcio、Rekor、
KMS；2.x 稳定，默认 ECDSA-P256 + SHA-256）；TUF 管更新元数据一致性。
构建产物 / SBOM / attestation / 安装包 / 更新 manifest / 功能证据包**各有独立 digest**。

### 1.3 WebView：穷尽度要用**攻击路径反推**，不能只列 CSP 头

```
Web 内容 → preload → capability → Rust command → 文件/网络/进程
```

每个 command 必须答：是否可由**不可信 origin** 触发 · 参数是否白名单 ·
是否跨窗口共享 · 返回数据是否含**系统路径或令牌** · 能否改变持久状态 ·
错误是否泄漏**绝对路径或内部 URL**

CSP 逐个区分 `default-src` / `script-src` / `style-src` / `img-src` /
`connect-src` / `frame-src`，尤其 `tauri://`、`http://tauri.localhost` 与**多 WebView**。
禁止 `unsafe-inline`、`unsafe-eval`、远程任意脚本（除非逐条豁免+签名证据）。

preload 只导出窄接口，**不在全局挂 `window.__api`**；所有 `postMessage` 校验
origin/source/schema/幂等键。

> ⚠️ **URL handler 与拖放文件把用户输入当命令或路径，是典型权宜设计** ——
> 原版若双击任意文件路径就执行联网动作，目标必须拆成「打开—解析—预览—确认—执行」。

Nuclei 模板：`update-manifest-tamper` · `unsigned-update-asset` ·
`ipc-command-injection` · `webview-file-origin` · `postmessage-origin-missing` ·
`deep-link-scheme-injection` · `privileged-api-exposed`
⚠️ Nuclei 明确提示"积极开发中可能有破坏性变更" → **模板与 CI 必须锁 commit/版本**。

### 1.4 凭据：**默认答案是否定**

🚫 不应把 DPAPI blob 直接搬到新格式 ·
🚫 不应在跨用户/跨设备/跨 profile 时假定可解密 ·
✅ 目标端默认不迁移 · ✅ 不清空旧凭据但不批量复制 · ✅ 提供显式重新登录

> ⚠️ 若原版"明文记住密码"被用户视为功能 → **保留功能但改成系统钥匙串**，
> 并生成前后路径、权限与撤销证据 ——
> **不能因"体验一致"复制不安全实现**。

### 1.5 沙箱：可验证场景，不是一句"Rust 更安全"

Windows AppContainer/MSIX、Job Object、低完整性令牌、LPAC；
Linux seccomp/landlock/namespaces/XDG/Wayland 门户；
macOS entitlements/sandbox/Hardened Runtime/notarization ticket。

> ⚠️ **每个 capability 必须有一条正向成功路径 + 一条负向拒绝路径。**
> 若某平台无法提供相同能力 → **显式降级或禁用，而不是静默返回成功。**

## 二、B 类：离线与网络不确定（**完全空白**）

```bash
python3 scripts/network_resilience.py --layers    # 四层检测
python3 scripts/network_resilience.py --faults    # 25 个具名故障
python3 scripts/network_resilience.py --proxy     # 企业网络不是一个布尔值
python3 scripts/network_resilience.py --retry     # 围绕业务幂等性
```

> 🔑 **原版"能离线用"是可用状态机，不是一句错误提示。**
> 结论不能写"断网提示用户"，而应写「**原版在第几次失败、累计多少毫秒后
> 显示什么文案，目标必须同事件序复刻；后台任务必须去重**」。

### 2.1 四层检测（`navigator.onLine` 只说明部分事实）

`link` → `dns` → `ip_routing` → `http_probe` / `tls_handshake` →
`proxy_auth` → **`application_health`** / `captive_portal`

> **真正决定原版行为的是具体域名、协议、端口、认证、TLS 与业务响应。**
> 状态迁移只能依据明确事件，**不把 online→offline 的瞬时 DNS 失败直接映射成数据丢失**。

**降级矩阵**（先按真实路径采集，再决定目标是否"足够好"）：
启动无网 · 首次登录无网 · 编辑中掉线 · 附件上传中掉线 · 下载中掉线 ·
证书错误 · 企业代理 · PAC/WPAD · NTLM/Kerberos · TLS 拦截 · 慢速响应 ·
HTTP 重定向 · DNS 失败 · 断点续传 · 幂等重试 · 后台唤醒重试

每项记录原版**提示文字、出现时机**、是否允许重试、是否生成草稿、
是否会**重复提交**、是否暴露技术错误。

### 2.2 25 个具名故障场景

`dns_nxdomain` `dns_timeout` `dns_slow` `tls_cert_untrusted`
`tls_ca_intercepted` `tls_expired` `tls_wrong_host` `proxy_refused`
`proxy_auth_407_ntlm` `proxy_loop` `http_502` `http_504` `redirect_loop`
`slow_start` `slow_body` `stall_after_headers` `bandwidth_50kbps`
`latency_2000ms_jitter` `packet_loss_10pct` `connection_reset`
`read_timeout` `write_timeout` `server_slow_close`
`captive_portal_redirect` `ipv6_blackhole`

每项定义：入口条件 · 注入层 · **原版期望** · 目标期望 · 恢复阈值 ·
用户提示 · 重试策略 · 幂等策略

⚠️ Clumsy（Windows）与 tc-netem/Comcast（Linux）**只作手工探索与注入，不进默认门禁**。

### 2.3 企业网络不是"支持代理"一个布尔值

系统代理 · PAC · WPAD · 自动检测 · 手工代理 · SOCKS · HTTP CONNECT ·
NTLMv2 · Negotiate/Kerberos · 代理凭据提示 · CA 拦截 · 客户端证书 · 代理旁路 · 白名单

⚠️ WebView 与原生 HTTP 客户端**不得假定使用同一代理状态** ——
分别记录 Tauri WebView 配置、WinHTTP/WinINet 语义、Rust `reqwest`/系统解析器、**PAC JS 特性差异**。

⚠️ **企业 TLS 拦截测试默认不应把根 CA 导入个人信任库** —— 只属受控测试 profile，证据必须可销毁。

### 2.4 重试围绕**业务幂等性**

`method` · `uri_template` · **`idempotency_key`** · `retryable_error_codes` ·
`max_attempts` · `base_delay_ms/max_delay_ms` · `jitter_ratio` ·
`circuit_breaker` · `timeout_connect/read/whole` · `request_hash` · `response_etag/digest`

验证：首次 200 后第二次也成功 → **不得创建重复对象**；
首次超时后重复成功 → **不得静默覆盖**；第二次返回 409/412 → 按契约处理；
代理在 body 中途断连 → **不得把 TLS 错误转成普通网络错误**。

## 三、C 类：辅助功能与 **IME**（IME 完全空白）

```bash
python3 scripts/a11y_ime.py --ime            # 🔴 最容易让复刻失败
python3 scripts/a11y_ime.py --ime-schema     # 事件字段
python3 scripts/a11y_ime.py --screen-reader  # NVDA 朗读事件序
python3 scripts/a11y_ime.py --tree           # AccessKit 中立桥接
python3 scripts/a11y_ime.py --contrast       # 强制颜色/动效/缩放
python3 scripts/a11y_ime.py --keyboard       # 键盘与输入法联合
```

### 3.1 🔴 IME：最容易让"像素复刻"失败的隐藏交互层

**全事件序列**（每项都要录）：焦点进入 → `compositionstart` →
每次按键后的 `compositionupdate`/`input`/`textInput` →
**候选窗口弹出/移动/翻页/横排竖排/数量变化** → 候选选择 → `compositionend` →
最终 `input` → 光标位置 → 删除/方向键 → **Esc 取消** → **Enter 确认** →
标点模式 → **全角/半角** → **简繁转换** → 直接输入与转换混用 →
**焦点切换时未确认 preedit 的提交或丢弃** → 窗口失焦/多显示器/远程桌面/不同 DPI/不同 WebView

**事件 schema**：`before_value` · `composition_text` · `pending_commit` ·
`selected_candidate_index` · `candidate_page` · `cursor_offset` ·
`focus_id` · `editing_rect` · **`composition_rect`** · **`candidate_rect`** · `action`

> 🔑 **验收单位是"可观察状态序"，不是"最终汉字相同"。**

规则：
- React 须区分**受控值、合成字符串、最终值**
- `onChange` **不得用最终值覆盖 `inputType`**
- 输入框**不得把组合文本拆成多份**
- 粘贴/撤销/输入法/**语音输入**共存时不得破坏受控状态
- 通过 CDP/DevTools Protocol 或注入探针记录 —— **不依赖"看起来已经上屏"**
- 候选窗口遮挡输入区 → 验自动滚动、视口避让、多显示器边界、DPI 缩放、最小化恢复
- **目标不得只在单语 Windows 11 默认输入法下通过**

### 3.2 屏幕阅读器：价值在**朗读事件序**

固定：Windows 显示语言、TTS、语速、NVDA 版本、浏览器/WebView 版本、区域、**输入法**
导出：开启 **Speech Viewer** 后导出文本流
归一化：合并重复空格、忽略时间戳、**动态数值放占位符**、保留角色/状态 token

断言项：首次聚焦朗读 · 状态变化朗读 · 插入/删除项 · 错误关联 · 对话框标题 ·
模态焦点捕获 · 焦点返回 · **实时日志是否打断输入**

> ⚠️ **朗读对比必须保留原始 trace，不能只留"通过/不通过"。**
> ⚠️ **不应把"aria 快照无错误"当作可访问性复刻完成。**
> VoiceOver/Orca/Narrator/JAWS 进**季度手工基线池** —— 版本差异本身就是证据。

### 3.3 辅助树：AccessKit 作中立桥接

WPF UIA（AutomationId/Name/ControlType/LocalizedControlType/Value/IsEnabled/HasKeyboardFocus）
· Patterns（ExpandCollapse/Scroll/Selection/Table/Grid）· 几何与文本 ·
AccessKit（整数 ID + role + 可选属性，Rust 是规范定义）→ 映射 Web AOM 与 Tauri WebView

新增 `legacy_role` 与 `missing_equivalent`。
⚠️ 原版若"文字不标准但读得对"，目标**不能复制"裸 div"** ——
应补 `aria-label`/`aria-labelledby`/`role`，并在 NVDA trace 中**证明结果等价**。

### 3.4 强制颜色 / 对比度 / 动效 / 缩放

Windows 高对比度 · `forced-colors` · 深色/浅色 · 用户色覆盖 · 系统动画开关 ·
`prefers-reduced-motion` · `prefers-contrast` · 页面缩放 · 仅放大文本 ·
**最低 200% 文本缩放** · 窄窗口重排

检查：颜色替换是否**破坏状态指示** · 边框是否消失 · **图标是否只剩颜色** ·
过渡是否**留在半透明态** · 缩放是否截断按钮 · 长标签是否改变布局

> **Playwright/像素比对负责外观，axe/AccessKit 快照负责语义 —— 两者缺一不可。**

### 3.5 键盘与输入法必须联合

Tab/Shift-Tab · **visible focus** · Roving Tabindex · 箭头 · Home/End ·
PageUp/Down · Esc · Enter · Space · 修饰键 · **快捷键冲突** ·
**IME 下 Enter 与候选确认** · **Esc 取消组合** · **方向键选候选** ·
Caps/Num Lock · **Sticky/Filter/Toggle/Mouse Keys** · 开关控制 · 语音输入

> ⚠️ **若原版在 IME 开启时快捷键失效 → 这是行为基线而非缺陷**，
> 目标应保留并在 `keyboard-legacy.md` 注明。

⚠️ 远程桌面、屏幕键盘、眼动、开关访问、语音输入必须进 C 级基线 ——
它们会显著改变焦点、候选窗口、文本组合、滚动、可见性和确认方式。

## 四、D 类：能源、后台与系统资源

**电源状态是可见功能状态，不是遥测开关。**
AC / 电池 / 低电量 / 节能模式 / 性能模式 / 睡眠 / 休眠 /
**Modern Standby(Connected Standby)** / 盖子关闭 / 快速启动 / 混合唤醒 / 定时器唤醒

WPF 常见的后台动画、定时器轮询、未冻结 Storyboard、Render 循环 →
映射为 `requestAnimationFrame`、WebView 可见性、定时器、Worker、通知轮询、Rust 任务节流。

**EcoQoS/后台节流是显式选择，不应由框架默认猜。**
`SetProcessInformation`/`ProcessPowerThrottlingState` + QoS。
⚠️ **并非"越省电越好"** —— 交互输入、下载校验、媒体播放、定时提醒对延迟敏感，
应保留前台或提高优先级；可推迟的同步/压缩/缓存清理/索引才适合 EcoQoS。
迁移前先写 `energy-budget.md`，每类任务标注
`realtime` / `interactive` / `background/best-effort`。

**混合显卡与多显示器**：GPU 偏好 · 集显/独显切换 · 外接显示器热插拔 ·
刷新率变化 · HDR · DPI 变更 · **显示器移除与窗口恢复**
⚠️ 目标不得假定 WebGPU/WebGL 使用同一 GPU。

**泄漏从原版资产清单反推**：句柄 · **GDI 对象** · User 对象 · 线程 · 定时器 ·
文件锁 · 内存映射 · COM 引用 · DirectX 资源 · WebView 进程 · Worker ·
EventSource/SSE/WebSocket · 数据库事务 · 字体缓存 · 托盘图标 · 剪贴板监听 · 命名管道

> WPF 中常见但常被忽略的 GDI 泄漏：未释放的 `Bitmap`/`Brush`/`Pen`、
> ImageSource/Icon 缓存、`RenderTargetBitmap`、剪贴板大图。
> ⚠️ **Rust 内存安全 ≠ 无资源泄漏。**

## 五、E 类：法律合规与证据链

> ⚠️ **CI 能验证的是证据存在，不能证明法律风险消失。**

**Fides**（`ethyca/fides`，Apache-2.0）管数据地图与主体权利请求 ——
`compliance/privacy-map.yml` 记：数据主体、字段、分类、存储位置、系统组件、
处理目的、合法基础、保留期、接收方、跨境/第三方、加密、访问控制、导出/删除路径。

⚠️ **不能让 CI 输出"GDPR 合规"或"中国法合规"的结论。**

**无障碍法规要转成可发布的声明**（VPAT/ACR 模板），按功能/组件记
符合/部分符合/不支持/未评估 —— ⚠️ **一张 VPAT 不能声称全球适用**
（中国信息无障碍、Section 508、EN 301 549、ADA 适用范围不同）。

**专有软件复刻的法律边界**：`legal/evidence-ledger.md` 登记来源渠道、
购买/授权凭证、哈希、工具、人员隔离、访问隔离、时间线、
仅接触规格者/仅接触实现者、设计决策、审查结论。

> ⚠️ **clean room 不是法律结论，只是支持"独立来源"的证据之一。**
> 是否构成合理使用仍需个案判断 —— **必须当地律师核验**。

**出口管制与加密声明要作为发布门禁**：`component` · `algorithm` · `key_size` ·
`purpose` · `export_review_required` · `official_classification` · `evidence_url`
⚠️ **没有官方分类时写"未确认"，禁止推断为"无管制"。**

## 六、❌ 本轮冲突项

| 做法 | 为什么冲突 |
|---|---|
| **时间戳后签名永久有效** | Lifetime Signing OID 会推翻 |
| 用"Sigstore 已存在"替代原生安装器签名 | 平台签名各有要求 |
| 只检查 `ValidSignature` | 漏掉吊销/根轮转/TSA 不可达 |
| **把 TUF Python 实现当生产依赖** | 参考实现不是稳定 API |
| 把 DPAPI blob 直接搬到新格式 | 跨用户/设备不可解密 |
| **因"体验一致"复制明文凭据** | 应换系统钥匙串并留证据 |
| 某平台无能力时**静默返回成功** | 应显式降级或禁用 |
| **"断网提示用户"** | 应复刻第几次失败/累计多少毫秒/什么文案 |
| `online === navigator.onLine` | 只说明部分事实 |
