# 体验维度总清单（参数与资产之外的全部）

> **本篇管什么**：`体验参数挖掘.md` 管**数值**（tips 延迟 500ms），
> `资产与资源总清单.md` 管**素材**（图标/字体/音效）。
> 本篇管**剩下所有用户能感知的东西**——文案、错误态、可访问性、性能、系统整合……
>
> **共同特征**：功能清单上不会写，README 也不会写，
> 丢了之后用户说"感觉变了但说不出哪里变了"。

## C1 · 文案与语言 ★★（最常被直接重写的一类）

| # | 项 | 说明 / 坑 |
|---|---|---|
| C1-1 | **全部 UI 文案全集** | 按钮、标签、标题、菜单、提示、占位符 |
| C1-2 | **错误提示文案** ★ | 逐条记录原文，新版常换成"自己觉得更清楚的"，用户反而找不到 |
| C1-3 | 成功 / 警告 / 确认对话文案 | |
| C1-4 | 空态文案 | 各类空态可能不同 |
| C1-5 | 加载文案 | "加载中…" 具体措辞与省略号 |
| C1-6 | **术语一致性** ★ | 同一个东西在不同页面叫法不同（"文件夹/目录/分组"三选一了吗） |
| C1-7 | 占位符与示例文本 | |
| C1-8 | **截断与省略规则** ★ | 超长文本：省略号？Tooltip 补全？截断位置？ |
| C1-9 | 中英混排 / 数字与单位空格 | "5 个" vs "5个" |
| C1-10 | 大小写与标点风格 | 句末句号有无、全角半角 |
| C1-11 | 键盘快捷键提示 | "Ctrl+S" 还是 "⌘S" |
| C1-12 | 文案中的动态插值 | `{0}` / `{name}` 位置，翻译时顺序会变 |

**⚠️ 迁移时最常见的错误**：不看原文案，直接"重写得更清楚"。
用户的肌肉记忆是认**原句**的，换了措辞等于换了入口。

自动提取与差集：`scripts/text_extract.py`

## 怎么用

1. 每类逐项打勾，编号建议 `VD-<类别>-<序号>`（如 `VD-C1-2`）
2. 挖不动时对照本表查"还有哪一类没碰过"
3. 三类自动提取脚本：
   - 文案 → `scripts/text_extract.py`
   - 参数 → `scripts/param_extract.py`
   - 资产 → `scripts/asset_inventory.py`

**一句话**：功能清单决定"有没有"，
参数决定"手感"，资产决定"长得像不像"，
**本篇决定"能不能用、会不会丢数据、合不合法"。**
