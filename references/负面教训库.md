# 负面教训库（跨平台复刻必看）

> 这类陷阱**只在特定平台出现，但一旦出现就是致命的**。
> 照着功能清单做完，会发现"黑屏""点不动""错位"——**原因根本不在功能逻辑里**。

---

## 一、平台陷阱表

| 陷阱 | 平台 | 后果 |
|---|---|---|
| 逐像素 α 被当不透明 | Windows 分层窗口 | **渲染成整屏黑** |
| α=0 区域点击穿透 | Windows 分层窗口 | 覆盖层**完全收不到点击** |
| 模态 `Show()` 后降级 | WPF | `DialogResult` 抛异常 |
| 无边框最大化向内缩进 | WPF | 左/顶**露出一条桌面** |
| 无边框最大化盖住任务栏 | Windows | 需 `WM_GETMINMAXINFO` 钳制 |
| 高 DPI 未处理 | 全部 | 截图/取色**错位** |
| 管道缓冲区填满死锁 | 全部 | 需"先启动异步读再等退出" |
| 双端滚动同步振荡 | 全部 | 第二次 ScrollChanged 触发反向对齐 |
| 表格列信息不可靠 | Markdig | `ColumnIndex` 恒 -1 + 幻影列 → **首列丢失** |
| 8.3 短名不匹配 | Windows | 输入需先展开完整路径再匹配 |
| 无 BOM UTF-8 被读成乱码 | 全部 | Unicode 解码几乎不抛异常 → 回退永不触发 → **乱码写回成脏数据** |
| `+h` 会让文件夹被隐藏 | Windows | 设置图标只加 `+s` 不加 `+h` |
| 图片未真正转 ICO | 全部 | 改图标可能**根本不生效** |
| 中文路径构建坑 | Windows PS 5.1 | dotnet 子进程按 GBK 破坏路径参数 |
| 任务栏固定图标不自动更新 | Windows | 按固定那一刻缓存，需删重建 .lnk |

## 二、原版实证注释（可直接作为检查项）

```
不设 Handled：普通单击仍走 Button Click
不能用 Hide()/Show()——模态对话框 Show 后会被降级（E006）
纯 Transparent（α=0）会整体点击穿透，故底刷用 α=1 近不可见黑
必须分层真透明——否则被当不透明渲染成整屏黑
EventSetter 会创建 code-behind 新实例，其 DataContext 为空（全树不可选中）
Markdig 表格 ColumnIndex 恒为 -1，还常含 1 列幻影——否则首列丢失
第二次 ScrollChanged 会逃逸触发反向对齐，两端来回微调成振荡
```

## 三、样式系统通用坑（XAML ↔ CSS 完全对应）

```
BorderBrush 放 Style Setter 而非本地值  → CSS: 避免 !important
模板内触发器优先级高于 Style.Triggers   → CSS: 选择器特异性
自定义色触发器必须排在默认之后          → CSS: 规则顺序（后者为准）
```

## 四、并发类陷阱

| 陷阱 | 后果 |
|---|---|
| 只在写时加锁，load 与 save 不在同一临界区 | 读-改-写覆盖，改动整份丢失 |
| 锁不可重入 | 事务嵌套 = 自己等自己，死锁无提示 |
| 异常路径不放锁 | 用 RAII（drop 释放），不要手动 unlock |
| 信注释里的"单进程"假设 | 实证：`--mcp` 是独立进程，假设是错的 |
| 抢锁而非超时报错 | 主动制造覆盖冲突，代价不可逆 |

**临时摘锁 / 抑制模式，必问三个问题**：
1. 状态是在窗口**外**读的吗？（窗口内读出来是假的）
2. 有没有 `finally`？（没有的话异常时锁摘不回来）
3. 可重入吗？（嵌套调用会不会提前把锁戴上）

## 五、数据类陷阱

| 陷阱 | 后果 |
|---|---|
| 读不出来静默返回默认值 | 下次保存整份覆盖 → 原文和用户数据两头空 |
| 检测到损坏但不拦写入 | 唯一可抢救的线索被覆盖 |
| 整份覆盖写 | 吃掉别人写的段（`[LocalizedFileNames]`、`[ViewState]`） |
| 先试 UTF-8 失败再回退 UTF-16 | 回退永不触发，乱码写回成永久脏数据 |
| 字段数对得上就认为等价 | 实证：两层锁定合并成一层 → "仅账面固定"这一档消失 |

## 六、流程类陷阱

| 陷阱 | 后果 |
|---|---|
| 只扫命令清单 | 漏掉独立弹窗里的功能（类型 B） |
| 只按行数倒序选文件 | 漏掉中等文件整档（最大盲区，实证整档从没打开过） |
| 只提取 `///` | 漏掉最有价值的踩坑记录（实证单轮相差 60 项） |
| 假设"当前是原版的子集" | 漏掉改名 / 合并 / 反向差异 |
| grep 单行抓结构体字段 | 漏掉带泛型 / `Option` 的字段（实证 25 vs 39） |
| 把使用说明当事实 | 照着不存在的功能做一遍 |
| 复刻时对齐原版删掉增强项 | 越复刻越倒退（必须维护反向清单） |
| 清单说有就照做 | 实证 #515 本来是对的，照做反而引入 bug |
