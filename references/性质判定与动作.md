# 性质判定与动作

> **一句话**：性质是判断，**动作是结论**。只打性质标签不算判定完成。

---

## 一、六类性质 → 五个动作

| 性质 | 识别信号 | 动作 | 判错的后果 |
|---|---|---|---|
| **设计意图** | 注释写明"因为业务需要"；去掉后体验/正确性受损 | **preserve** | 当成妥协换掉 → 体验丢失 |
| **技术权宜** | 手写了一段本该由库/平台提供的能力；注释含"暂无""只能用""手动" | **replace** | 照抄 → 搬来技术债 |
| **平台限制** | 依赖特定 OS / 运行时行为 | **preserve / defer** | 误判为权宜 → 换掉后跑不起来 |
| **历史债** | TODO / FIXME / 已废弃的兼容代码 | **remove** | 留着 → 新版继续发酵 |
| **无意识坏味** | 复制粘贴、命名混乱、边界遗漏 | **merge / 修正** | 照抄 → bug 复制一遍 |
| **优秀实践** ⭐ | 全项目唯一一套规则、有防御、有注释说明"为什么" | **preserve + 推广** | 重写时丢失 → 新版反而更差 |

---

## 二、动作的义务

| 动作 | 必须证明什么 | 不证明会怎样 |
|---|---|---|
| **preserve** | 说明"去掉它会受损"（对设计意图）；说明"好在哪"（对优秀实践） | 后人不知道为什么不能改，早晚被"优化"掉 |
| **replace** | 新平台能力为何更好 + **边界行为如何等价**（错误文案、失败回退、极端输入） | 换方案最容易丢的，就是丑实现里藏着的边界处理 |
| **merge** | 前置条件 / 权限 / 异常 / 幂等 / 重试 / 缓存 / 可观测性 **全部等价** | 结构相似但语义不同 → 制造隐性 bug |
| **remove** | 无调用方、无数据残留依赖 | 删掉还在用的东西 |
| **defer** | 登记进 unknown，写明所需条件 | 悄悄变成永久缺口 |

---

## 三、判定口诀

> **去掉它，体验或正确性会受损吗？**
> 会 → 设计意图；
> 不会 → 看是不是当年没得选；
> 没得选 → 技术权宜，换掉。

**补一条**：
> **它是不是比你现在想写的方案更好？**
> 是 → 优秀实践，preserve + 推广。

## 四、实证分类表

| 原版做法 | 性质 | 动作 | 理由 |
|---|---|---|---|
| 跨进程命名 Mutex | 设计意图 | preserve | 真有两个进程 |
| 官方 API 优先 + 直写回退 | 设计意图 | preserve | 缓存由系统维护 |
| 双端滚动 33ms 防抖释放 | 设计意图 | preserve | 防振荡 |
| 写 desktop.ini 直写 | 技术权宜 | replace | 改用官方 API（#504） |
| 手动累加高度算列表高度 | 技术权宜 | replace | 用 `getBoundingClientRect` 实测（#734） |
| 自绘 ICO 转换 | 技术权宜 | replace | 用成熟库（原版 A2 就是这坑） |
| 轮询目录指纹 | 平台限制 | preserve | iframe 里 emit 不可达（可换增量指纹） |
| stdio JSON-RPC | 架构选择 | preserve | 但文档必须写清 |

## 五、判定表格式

| 编号 | 功能 | 原位置 | 证据等级 | 性质 | 动作 | 理由 | 保留要点 |
|---|---|---|---|---|---|---|---|
| #101 | 跨栏拖到空白=换栏移动 | DragService.cs:88 | runtime-verified | 设计意图 | preserve | 通路被当错误处理堵死 | 落点栏=目标栏当前 activeTab |
| #504 | desktop.ini 直写 | IconSvc.cs:201 | static-code | 技术权宜 | replace | 官方 API 可即时生效 | 回退路径必须保留（G-2） |

**没有动作标签的条目 = 没判。**

---

## 六、判定不出怎么办

**不许默认 preserve。** 默认 preserve 会把技术债全搬过来。

| 情况 | 处置 |
|---|---|
| 证据不足 | 补证据；补不上 → 进 unknown |
| 判不出性质 | 进 unknown，写明需要什么信息才能判 |
| 想 merge 但证明不了等价 | 保留并行实现 + **注明差异**，不要硬合 |
