# 许可合规与 SBOM（L 类升级：从"待确认"到可阻断）

> **为什么升级**：`asset_inventory.py` 目前只对字体/音效/图标/图片标"待确认"，
> 但没有状态机、没有阻断能力。
> **字体许可是像素级复刻最容易忽略的红线。**

---

## 一、四态（不是统一标"待确认"）

| 状态 | 含义 | 放行 |
|---|---|---|
| `confirmed_allowed` | 有许可证文本 + 允许当前使用方式 + 已留存证据 | ✅ |
| `confirmed_restricted` | 需替换 / 需联系授权 / 需改变交付方式 | ❌ **阻断** |
| `unknown_evidence` | 发现组件但许可证证据不足 | ❌ **阻断** |
| `not_applicable` | **仅限**内部自研代码且通过审批 | ✅ |

**任何 `confirmed_restricted` 或 `unknown_evidence` 阻断交付。**
**不许用功能完成替代许可完成** ——
允许用更优设计替代原实现，**不允许用侵权替代原版字体**。

---

## 二、工具（真实仓库）

| 工具 | 仓库 | 用途 |
|---|---|---|
| **ScanCode Toolkit** | `aboutcode-org/scancode-toolkit` | 许可证、版权、包、依赖扫描（源码与二进制） |
| **Syft** | `anchore/syft` | 生成 SPDX / CycloneDX **SBOM** |
| **Grype** | `anchore/grype` | 消费 SBOM 做漏洞匹配 |
| **cargo-deny** | `EmbarkStudios/cargo-deny` | Cargo workspace 的许可 / 通告 / 来源 / 重复依赖 |
| **licensee** | `licensee/licensee` | 按文本匹配识别开源许可证 |
| **REUSE** | `reuse-tool/reuse` | 让许可与版权信息机器可读 |
| **ClearlyDefined** | clearlydefined | 汇总组件许可与来源数据 |
| license-checker / pip-licenses | 各生态 | Node / Python 依赖许可清单 |

**⚠️ 每个工具只覆盖自身生态**：
cargo-deny 只管 Cargo，license-checker 只管 Node，pip-licenses 只管 Python ——
**都不能替代对 WPF 原版第三方组件的扫描**。

**必须同时生成** `bom.original.spdx` 与 `bom.tauri-react.spdx`，再做差集：
新增 / 移除 / 许可变化 / 安全风险。

**SBOM 覆盖范围**：新版依赖 **+ 原版嵌入组件**
（WPF 安装包、MSIX/AppX、原生 DLL、运行时组件）。

## 三、字体专项 ★★

**字体许可可能分别限制**（同一家族不同字重/厂商/渠道规则可能不同）：

```
个人使用 / 商业使用 / 嵌入（文档内嵌 vs 应用内嵌）/
再分发 / 修改 / 网页托管（@font-face）/ 子集化 / 可下载性
```

**建议**：FontBakery 做字体文件质量检查，
结合 **OFL 官方 FAQ、SIL 许可文本、字体厂商 EULA** 人工判定。

**必填字段**（`scripts/license_gate.py --init` 会生成骨架）：
`font_name` / `version` / `copyright` / `trademark` / `embedding` /
`subsetting` / `redistribution` / `web_hosting` / `modification` /
`source_url` / `evidence_link`

**⚠️ 不得仅凭"网上找到免费版"或相似字体名推断授权。**
⚠️ 本报告不将任何第三方字体仓库作为 OFL 许可的最终依据。

## 四、动效门禁（静态截图比不出来的）

**FFmpeg / OpenCV 能做的**：何时开始变化、何时稳定、哪些区域移动。
**不能做的**：**仅凭像素自动识别缓动曲线**。

除非原版有可读取的动画定义或足够高质量采样，
否则只报告：持续时间 / 延迟 / 稳定帧 / 运动区域 / 可见速度变化 ——
**不直接断言 `ease-in-out`**。

**每个动画一张契约**（`scripts/motion_check.py --init`）：
`trigger` / `pre_state` / `post_state` / `capture_start_event` /
`capture_end_event` / `expected_duration_range` / `stable_region` /
`forbidden_region` / `frame_sample_rate`

**先上线**：持续时间 / 稳态 / 区域变化 / 禁止区域。
**不要**一开始就追求识别缓动曲线 —— 那需要已知控制点和约束。

> **"UI 动效回归"没有成熟统一开源项目，不应夸大现有能力。**
> 可验证的是帧抽取和通用图像/视频比对，
> 不是对 WPF `Storyboard`、Tauri/CSS 动画的语义理解。

## 五、无障碍（C3 从人工清单升级为两级门禁）

| 层 | 工具 | 覆盖 |
|---|---|---|
| **自动门禁** | **axe-core**（`dequelabs/axe-core`）、**@axe-core/playwright**、pa11y、Lighthouse accessibility | 规则、键序、焦点可见性、陷阱、对比度、名称、状态 |
| 原版侧采样 | **Accessibility Insights for Windows**（`microsoft/AccessibilityInsights-Windows`） | 焦点顺序、名称/角色/值、模式覆盖、事件完整性 |
| **人工门禁** | 真人 | 语义上下文、屏幕阅读器措辞、语音输出、复合交互 |

**⚠️ "新旧两侧无障碍树自动语义 diff"尚无成熟一站式方案** ——
必须自建归一化器（FlaUI/UIA 导出原版树 + Playwright `accessibility.snapshot()`
导出新版树 + 自建比对）。**不许宣称存在现成方案。**

**归一化键应是业务语义，不是 DOM/COM 路径**；
对"按钮—链接—图标按钮"等合理替换允许映射。

**冲突分类**：结构 / 文本 / 焦点 / 状态 / 事件 / 关系。

**⚠️ 该脚本判断的是"用户感知的等价性"**，
不能保证 NVDA / JAWS / Narrator 的实际行为一致。

**Windows 原版与新版 Web 的无障碍模型不同**，
不能要求控件类型或角色机械相等 —— 应比对**语义等价性**：
名称是否相同、可聚焦顺序是否一致、操作是否可达、状态是否可感知、焦点陷阱是否消失。

## 六、其他可用原语（组合成 harness，不是平台产品）

| 方向 | 工具 | 说明 |
|---|---|---|
| 动效帧分析 | FFmpeg、OpenCV | 抽帧 + 帧间差异 / 光流 / 显著变化点 |
| 国际化 | i18next、formatjs、Babel 插件 | 文案工作流；抽取应含 ICU 参数、复数、上下文 |
| 伪本地化 | pseudo-localization | 长度扩展 + 特殊字符 → 暴露硬编码、截断、拼接 |
| RTL | rtlcss、postcss-rtlcss、逻辑属性 | **自动镜像不能证明视觉正确**，仍需逐状态截图 |
| 性能 | Lighthouse CI、k6、Playwright tracing | **必须测新旧同状态**，不只报新版绝对指标 |
| Schema 迁移 | Flyway、Liquibase、Atlas、migra、Skeema | 本地私有格式需自研 `legacy_loader` 双读 |
| 时间旅行 | WinDbg TTD、Mozilla rr、libfaketime | **调试能力，不是常态视觉基线**（TTD 会改变运行开销） |
| mutation | StrykerJS、**Stryker.NET** | .NET 侧也有 mutation 框架 |

**性能门禁重点**：冷启动 / 窗口打开 / 首屏 / 大列表虚拟化 / 搜索 /
导入导出 / 滚动 / 内存增长 / 多次切换。
**新版更快不自动说明体验等价** ——
原版若有刻意延迟、渐进加载或确认反馈，应作为 S5 择优议题显式记录。

**数据迁移**：原样读旧文件（版本魔术、字段顺序、编码、时区、小数分隔符、
空值、枚举、校验和、加密压缩）→ 中间规范表示 → 新版 loader 回读。
字段差异分：保留 / 重命名 / 类型变化 / 语义变化 / 缺失默认值 /
精度损失 / 顺序变化 / 不可逆项。**未经双读验证的迁移不进入 S6。**

## 七、脚本

```bash
python3 scripts/license_gate.py --init ledger/licenses.md      # 四态台账骨架
python3 scripts/license_gate.py --check ledger/licenses.md --gate
python3 scripts/license_gate.py --scan-bom                     # SBOM 工具清单
python3 scripts/motion_check.py --init motion/                 # 动效契约骨架
python3 scripts/motion_check.py --video old.mp4 --out motion-old.json
python3 scripts/motion_check.py --compare --old motion-old.json --new motion-new.json --gate
```
