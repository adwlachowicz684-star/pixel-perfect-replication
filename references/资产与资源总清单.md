# 资产与资源总清单（样式 / 美术 / 颜色 / 动效 / 阴影 / 音效 …）

> **立场**：视觉像素藏在**资源**里，不在逻辑里。
> 功能清单上不会写这些，README 也不会写——**不整份扫一遍就会整类丢失。**
>
> 本篇按 A–O 分十五类，尽量穷举（含"你多半没想到但迁移一定会踩"的几类，
> 特别是 **I 状态样式矩阵**、**L 许可合规**、**M 系统整合资源**、**B 动效中断**）。

---

## A. 颜色系统

| # | 项 | 说明 / 常见坑 |
|---|---|---|
| A1 | 品牌主色 / 辅色 / 强调色 | 含各深浅变体 |
| A2 | **语义色**（成功/警告/错误/信息） | 新版常换语义色库，必须记录原色值 |
| A3 | **中性灰阶** | 有没有成体系的阶（如 0-1000），还是随手抓的灰 |
| A4 | 背景层级色 | 页面底 / 卡片 / 浮层 / 遮罩 / 模态蒙层 |
| A5 | 文本色层级 | 主要 / 次要 / 禁用 / 占位符 / 反色（深色底上的字） |
| A6 | 边框色 / 分割线色 | 与阴影的分工 |
| A7 | **渐变** | 类型（线性/径向）、角度、**色标位置**（不是只记两个端点色） |
| A8 | **透明度层级** | 整套 alpha 体系，不是一个 opacity |
| A9 | 暗色模式 | 有没有？各色在暗色下的映射 |
| A10 | 高对比度 / 强制颜色模式 | Windows 高对比度下会不会崩 |
| A11 | 系统色整合 | 是否跟随 Windows 强调色（accent color） |
| A12 | 选中高亮 / 拖拽指示 / 插入条色 | 交互态专用色，极易漏 |
| A13 | **硬编码 vs token** | 硬编码色散落各处 → 新版应抽 design token |
| A14 | 颜色格式 | `#RRGGBB` / `#AARRGGBB`（WPF 带 alpha 在前）/ `rgb()` / 命名色 |

**⚠️ WPF 陷阱**：XAML 是 `#AARRGGBB`（alpha 在前），CSS 是 `#RRGGBBAA`（alpha 在后）。
**照抄会变成完全透明或完全不透明。**

## I. 状态样式矩阵 ★★（最常被漏的组织方式）

**不要按控件记样式，要按「控件 × 状态」矩阵记。**
少了任何一格，用户就会遇到"某个状态下长得不对"。

| 状态 | 必记 |
|---|---|
| normal | 默认样式 |
| hover | 悬浮 |
| pressed | 按下 |
| **focus** | 焦点（鼠标点击后） |
| **focus-visible** ★ | 键盘焦点（与 focus 不同！常漏） |
| disabled | 禁用（颜色/透明度/光标/是否响应事件） |
| selected / active | 选中 |
| loading | 加载中 |
| error | 错误态 |
| readonly | 只读（与 disabled 不同：可选中可复制） |

**还要记**：
- **触发器优先级与顺序**（XAML ↔ CSS 完全对应，见 `method/01`）
- 复合态（hover + selected、disabled + selected）

## L. 许可与合规 ★★（最容易忽略，代价最大）

| # | 项 | 为什么重要 |
|---|---|---|
| L1 | **字体许可** | 很多"免费字体"只允许个人使用，**商用/嵌入/再分发需授权** |
| L2 | 图标许可 | MIT / CC-BY（需署名）/ 商业授权，混用会违约 |
| L3 | 音效许可 | 同上 |
| L4 | 图片 / 插画授权 | 尤其从网上下载的素材 |
| L5 | 第三方库许可 | 依赖的开源库协议 |
| L6 | **许可证文件是否随包分发** | MIT 等要求保留版权声明 |

**迁移时资源往往被"重新下载一个差不多的"替代**——
如果原资源是商业授权，新版用免费替代品反而可能**丢失功能**（字重缺失、图标不全）；
反过来如果原资源是免费但需署名，新版漏掉署名就是**违约**。

**必须建一张资源来源与许可表**（见模板），逐条记录来源与许可。

## 怎么用这份清单

1. **逐类打勾**，每类至少产出一条 A-N 记录（编号建议 `AS-<类别>-<序号>`）
2. 挖不动时对照本表查"还有哪一类没碰过"
3. 资源文件本身用 `scripts/asset_inventory.py` 扫，本表负责"扫完之后还要人工判断什么"

**一句话**：功能清单决定"有没有"，本表决定"像不像、能不能用、能不能合法发布"。
