## 七类参数（逐类自检，不许留空）

| 类别 | 关键点 |
|---|---|
| **尺寸间距** | Margin / Padding / Width / Height / Gap / Spacing |
| **时序** ⭐最易丢 | tips 延迟、防抖、节流、轮询间隔、自动关闭、冷却、重试退避 |
| **动画** | Duration **与缓动曲线**（不只时长） |
| **阈值** ⭐最易丢 | 拖拽死区、滚动阈值、最小位移、容差、双击/长按判定 |
| **颜色透明度** | 主题色、Opacity、禁用态、hover 态 |
| **字体** | FontSize / Family / LineHeight / LetterSpacing |
| **层级/圆角描边** | ZIndex、CornerRadius、BorderThickness |

## 「性质」五选一（决定要不要照搬）

| 性质 | 含义 | 处置 |
|---|---|---|
| **等比迁移** | px→px 语义不变（圆角 4→4） | 照搬 |
| **需缩放** | 受 DPI / 字体度量 / DPR 影响 | 换算后**记下公式** |
| **平台惯例** | Windows 惯例 ≠ Web 惯例 | 记录差异，按新平台定 |
| **技术权宜** | 当年受技术限制 | ⭐ 换更好方案 |
| **有意变更** | 明确要改 | 登记 + golden 标 `intentional-change` |

## 源码里没有的：运行实测

有些参数代码里根本没有（系统默认滚动条宽、默认控件高、tips 实际延迟），
只有跑起来才看得到：

| 参数 | 怎么测 |
|---|---|
| tips 实际弹出延迟 | 录屏数帧 / 打点计时 |
| 动画真实时长 | 录屏按帧数 × 帧率 |
| 滚动条宽、系统字体度量 | 原版运行实测 + 截图量像素 |
| 默认控件尺寸 | 截图量像素 |

**证据等级标 `runtime-measured`**，写进证据卡并附测量方法。

## 三个提取陷阱（脚本已处理，手工挖时也要注意）

| 陷阱 | 后果 |
|---|---|
| `\bThreshold\b` 抓不到 `dragThreshold` | 驼峰命名的参数**全漏** |
| `FontSize` 与 `fontSize` 当两个参数 | 差集全是噪音，真差异看不见 |
| `TimeSpan.FromMilliseconds(180)` 被当秒 | **180 变 180000ms** |
| `Margin="8,4,8,4"` 被逗号截断 | 四元组只拿到 `8` |

**⚠️ 还有一条脚本处理不了**：
**XAML 是「左,上,右,下」，CSS 是「上 右 下 左」** ——
数值集合相同不代表等价，**别直接抄**。

详见 `../references/体验参数挖掘.md`。
