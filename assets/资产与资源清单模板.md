## 三、三类必须单独查的坑

### 1. 颜色格式（WPF ↔ Web）

```
XAML:  #AARRGGBB   （alpha 在前）
CSS :  #RRGGBBAA   （alpha 在后）
```
**照抄会变成完全透明或完全不透明。** 迁移时逐个换算，不能复制粘贴。

### 2. ICO 是否真的转了

原版 A2 修复记录：**图片未真正转 ICO → 改图标根本不生效**。
新版本清单里必须有"图标格式是否真实生效"这一栏，不能只写"有图标"。

### 3. 任务栏图标缓存

Windows **按固定那一刻缓存**图标，改了不生效，需**删重建 `.lnk`**。
这是部署脚本的一部分，不是代码问题。

- 原资源商业授权 → 用免费替代品反而**丢失功能**（字重缺失、图标不全）
- 原资源免费但需署名 → 新版漏掉署名就是**违约**

## 五、常见遗漏自检

- [ ] 各类**空态 / 错误页**插画（可能不止一套）
- [ ] **退场动画**（只做入场会很突兀）
- [ ] **focus-visible** 键盘焦点环
- [ ] 音效的**可关闭开关与默认值**
- [ ] **图标字体码位映射表**
- [ ] **z-index 层级表**（浮层/模态/通知/tooltip 各多少）
- [ ] **RTL 布局**（如果支持多语言）
- [ ] 系统整合资源：**托盘 / .lnk / 文件关联 / 高 DPI manifest**
- [ ] **孤儿资源**（存在但 0 引用）与**悬空引用**（引用了但文件没了）
- [ ] 资源的**许可证文件是否随包分发**

## 六、与体验参数的关系

| | 体验参数 P-N | 资产资源 AS-N |
|---|---|---|
| 管什么 | **数值**（tips 延迟 500ms、死区 6px） | **文件与规格**（图标、字体、音效、色板） |
| 提取 | `param_extract.py` | `asset_inventory.py` |
| 丢了会怎样 | 手感变了，说不出哪里 | 缺图、缺音、长得不对 |

**两者都要做** —— 一个管"节奏"，一个管"素材"。
