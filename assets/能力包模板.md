# 能力包模板（迁移粒度）

> **按"用户可观察能力"切，不按文件目录或文件大小切。**
> 一次只迁一个能力包，每步可回滚，验证未通过立即回退。

```markdown
# CAP-<domain>-<NNN>

## 1. 用户可观察结果（User-visible outcome）
用户把卡片从 A 栏拖到 B 栏空白区，卡片移动到 B 栏当前页签末尾。
（防止实现替代需求：写"用户能看到什么"，不写"调用哪个函数"）

## 2. 原版边界（Legacy surface）
- 窗口/页面：MainWindow
- 入口：拖拽手势（DragService）
- 快捷键：无
- API/命令：ResolveLinkDrop / moveCardAcross
- 文件格式：link-record.json

## 3. 命令/事件接缝（Contract seam）
| 项 | 值 |
|---|---|
| 命令名 | fpx_move_card_across |
| 参数 | kind: String, path: String, target: Option<String> |
| 结果 | union[ok, validation-error, io-error] |
| 失败模式 | 物理搬家失败 → 整体中止 |
| 幂等 | 同参数重放不产生重复记录 |

## 4. 数据形状（Data shape）
| 字段 | 类型 | 空值 | 默认值 | 备注 |
|---|---|---|---|---|
| target | string \| null | 可空 | null | null = 换栏移动 |

## 5. 原版证据集（Legacy evidence）
- 录制：goldens/raw/drag-cross-drop.json
- 日志：logs/legacy-2026-01-01.log:1120-1188
- 证据卡：EVD-DRAG-001 … EVD-DRAG-035
- 覆盖率：35/35

## 6. 新版接缝（Modern seam）
- 命令注册：src-tauri/src/main.rs
- 前端调用：plugins/project-group/api.ts → moveCardAcross()
- 错误处理：统一 runAction()

## 7. 发布门禁（Release gate）
- [ ] feature flag：`ff.drag.cross_column`
- [ ] 回滚方式：关闭 flag 即回退旧路径
- [ ] 双写/回读：无（纯前端交互，不涉及数据格式变更）
- [ ] 灰度：先内部

## 8. 异常路径录制（至少一个，S7 门禁 G7）
- [ ] 中途取消（Esc）
- [ ] 鼠标捕获丢失
- [ ] 目标栏为空
- [ ] 并发同发（连点）

## 9. 残留风险（Residual risk）
| 风险 | 等级 | 处置 |
|---|---|---|
| 换栏触发物理搬家，失败时状态不一致 | 中 | 后端整体中止（已有逻辑） |
| 高 DPI 下插入条位置偏差 | 低 | 已按布局坐标取值（#734） |

## 10. 状态
待迁 / 迁移中 / 已验证 / 已回滚
```

---

## 迁移顺序（每步可回滚）

```
1. 建立可执行原版与基线            （S1）
2. 建立命令 / 事件 / DTO 契约       （S4）
3. 先实现无副作用查询               （只读，最安全）
4. 再实现带审计的变更命令
5. 最后迁移副作用 / 文件 / 平台能力
```

**禁止一次性翻译全库。** 每个提交后系统仍可部署、仍可回滚。

**整栈迁移时接缝在哪**：WPF → Tauri+React 难以让两套 UI 同时渲染，
真正的接缝是**稳定的用户能力与命令边界**（打开/保存/导入/校验/预览/撤销），
不是"两套界面并存"。
