# 不得收工的判据

> **只要以下任何一条成立，就不得声明复刻完成。**
> 本文件是硬边界，不接受"大致""基本""暂时"。

## 一、六条硬堵（任一成立即阻断）

| # | 判据 | 为什么 |
|---|---|---|
| 1 | 存在**未读取**的原文件 | 没读过的文件里可能藏着功能 |
| 2 | 存在**未关闭**的 unknown | unknown 不是"没问题"，是"还不知道" |
| 3 | 存在**未验证**的字段 | 填了值不等于验证过 |
| 4 | 存在**未通过**的契约检查 | 契约是验收单位，不是参考 |
| 5 | 存在**未批准**的 golden diff | 差异必须有人看过并签字 |
| 6 | **人工门禁没签字** | 自动门禁全绿**也不等于完成** |

## 二、阶段闸门

| 阶段 | 不得进入下一阶段的条件 |
|---|---|
| S0 → S1 | 未锁定原版身份（构建号/哈希/协议版本） |
| S1 → S2 | 未定像素四维度口径、未建台账结构 |
| S2 → S3 | 台账有空 `legacy_value`、有未对照的"不能只…"项 |
| S3 → S4 | 任一条无分类、无证据等级 |
| S4 → S5 | 契约不可测（答不出"什么值算过"） |
| S5 → S6 | 偏离缺 owner 或缺到期日 |
| S6 → S7 | 有偏离未记录 |
| S7 → 完成 | 六条硬堵任一未清 |

## 三、🔴 最常见的"假完成"形态

| 形态 | 真相 |
|---|---|
| "功能都有" | **功能存在 ≠ 状态轨迹相等** |
| "看起来差不多" | 无逐帧/逐格 diff 支撑 |
| "平均延迟相同" | **相位可能完全不同** |
| "自动门禁全绿" | 大部分门禁只查"填没填" |
| "新版本兼容旧存档" | **只是宣传，不能证明** |
| "测试都过了" | 未做混沌验证，**门禁可能是假的** |
| "这个不重要先跳过" | 未分类即阻断，**没有"不重要"的默认档** |
| "以后再补" | 补的项必须有 owner + 到期日，否则等于永久丢失 |

## 四、反事实约束（原文）

> **只要存在未读取的原文件、未关闭的 unknown、未验证的字段、
> 未通过的契约检查或未批准的 golden diff，就不得声明复刻完成。**

## 五、唯一允许的"未完成但继续"

**`deferred_with_contract`**：非阻塞项连续两轮未通过且差异低于阈值，
可转为"带契约的延期"——**必须有：契约、owner、到期日、复审条件**。

**`blocked_until_evidence`**：must-match 证据无法取得时，
标注并停下——**而不是不断猜测实现**。

> 🔴 **除这两种，没有其他"先过再说"的形态。**
